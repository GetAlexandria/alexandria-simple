alexandria-simple

A personal Alexandria for two people and their AI colleagues. No factory, no hosting, no babysitting.

What this is

This repo is a snapshot of alexandria-internal pared down to the architecture Danvers and Jess actually run: the library, the playbook skills, the viewer, and named colleagues (Raven, Damien) who work on a schedule. Everything commercial-scale — the multi-tenant build factory, deploy and hosting machinery, the PMS/Studio surface, vendored dependency trees — is gone. What's left is a system with almost nothing that can break while you sleep.

The whole design, one paragraph

Files are the substrate — the library, the work board, and the colleagues' journals are plain git-tracked files anyone (human or agent) can read and edit. Git is sync and history — commits are how state moves between the two of you and between machines; there is no sync service. One viewer is the lens — a local web app that renders those files and owns no state of its own. And colleagues run a duty loop — a cron wakes each one every 30 minutes to check the board, git, and inboxes, do a bounded beat of work, journal it, and escalate anything that needs human judgment.

How a colleague's day works

Every 30 minutes, a headless session wakes as Raven: read the last journal entry, diff the board and git log since then, check email and calendar if connected. Anything clearly in remit and reversible — just do it, commit it. Anything that needs judgment — move the card to the Needs a Human lane with a note, and end the beat. Never block, never ping.

You sweep the lane in the viewer on your own rhythm; ruling on a card and moving it back hands it to the next beat. Urgent things skip the loop entirely — open a session and kick the colleague directly, like tapping a teammate's shoulder.

Setup (each machine, ~5 minutes)

  1. git clone https://github.com/GetAlexandria/alexandria-simple.git

    Private repo; you and Jess both have access through GetAlexandria.

  2. cd alexandria-simple && pnpm install
  3. bun packages/ax/src/cli/main.ts start viewer

    The viewer at http://localhost:4321 — library, board, and lanes, straight off the files in the repo.

  4. Authenticate the Gmail + Google Calendar connectors

    claude.ai → Settings → Connectors, for the account the cron will run as. Until then the duty loop's inbox checks quietly no-op — this is the first card waiting in the Needs a Human lane.

  5. Add the cron line (one machine that stays awake)

    The exact entry lives in docs/alexandria/duty-loop.md — the single source of truth for the loop: the command, the pull/push bracket that makes it multiplayer, and the escalation contract.
