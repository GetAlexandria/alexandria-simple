## Claim 1: Five-phase build sequence from one factory to federated smart company

### Content

The five-phase build sequence:

**Phase 1 — The Handshake:** Library + Factory = working context delivery.
- Bridget assembles briefings reliably for any active library area
- Eval scores show library-backed builds outperform non-library builds
- Feedback loop is running: assembly gaps feed back to construction priorities
- The service-to-construction loop drives priority, not just internal quality assessment

**Phase 2 — Close the Loop:** Library + Factory + Outside World = marketplace signal flowing back.
- External signal has a defined entry point through Solomon
- Signal Queue handles marketplace-origin claims
- At least one Strategy Cascade triggered by marketplace signal
- The full circuit is visible: library serves factory, factory ships product, product generates signal, signal challenges library, library updates

**Phase 3 — One Complete Node:** The milestone.
- Full circuit has run at least 3 complete cycles
- Measurable evidence of the traceable chain: signal changed card changed briefing changed output improved product
- Every step has a concrete mechanism and artifact
- This is the irreducible unit of the federated smart company — if this node works, the pattern is proven

**Phase 4 — The Second Factory:** Federation begins.
- Second factory (marketing/sales suggested) with its own vocabulary and retrieval profiles
- Shared context flows between factories without duplication
- Signal from second factory's marketplace feeds through the same loop architecture
- Cascade analysis works cross-factory

**Phase 5 — Repeat the Pattern:** If Phases 1-4 work, the federated smart company is repetition.
- Each new factory gets its own library with genus-appropriate vocabulary
- All factory libraries share corporate context via WHY chains
- The construction system works at any altitude with configuration, not code changes

The governing principle: build the next thing, but build it so it composes into the eventual architecture. **Architectural compatibility, not architectural completeness.**
