The Agent Team

Six agents, each with one verb. The outer layer is agentic (Raven), the inner layer is agentic (everyone else), and plays are the deterministic middle.

Raven the Maven

Thinks • Product partner • Outer agentic layer
Skills
  • /library — persistent room
  • /wizard — configuration
  • /plan — implementation planning
  • /revise-plan, /complete-plan
Dispatches
  • Solomon (signal triage)
  • Conan (health check, grading)
  • Sam (card construction)
  • Bridget (context assembly)
  • Nit (mechanical checks)
Produces
  • Conversation + strategic insight
  • Handoff blocks (Solomon/Feedback/Conan)
  • Agent dispatches

Solomon the Sorter

Triages • Epistemic gatekeeper • Robust but untested
Capabilities
  • 6 signal doors (meetings, directives, Slack, customer, Raven handoff, docs)
  • Tension detection T1-T7
  • Evidence protocol E1-E4
  • Settledness test (3 gates)
Produces
  • Tension briefs (5-field claim blocks)
  • Source material files
  • signal-queue.jsonl entries
Tools
  • alxndr tensions

Conan the Auditor

Grades • Quality guardian • Most important play
Jobs (9 types)
  • Grade (5D, weighted avg, A-F)
  • Diagnose (root cause analysis)
  • Recommend (surgery plans)
  • Health Check (6-phase)
  • Downstream Sync
  • Inventory, Spot-Check, Audit, Review
Tools
  • alxndr grade
  • alxndr lint (pre-grade)
  • alxndr scoreboard

Sam the Scribe

Creates • Card builder • Executes surgery plans
Capabilities
  • Build cards from inventory + source
  • Fix cards per Conan's plans
  • Self-check before handing to Nit
  • Batch construction (rationale → product → experience)
Does NOT
  • Grade cards (Conan's job)
  • Assemble briefings (Bridget's job)
  • Run lint checks (Nit's job)

Nit the Picker

Verifies • Mechanical linter • Deterministic
6 Sweep Levels
  • L1: Lines (formatting, frontmatter)
  • L2: Cards (dimensions, links)
  • L3: Graph (orphans, islands)
  • L4: Layers (type distribution)
  • L5: Library (coverage, counts)
  • L6: Cross-system (grades, plans, wizard)
Tools
  • alxndr lint (all sweeps)

Bridget the Briefer

Assembles • Context delivery • Value landing zone
Capabilities
  • 15 retrieval profiles
  • Task classification (target + task type)
  • U-shaped attention ordering
  • Gap manifest (honest about missing)
Produces
  • CONTEXT_BRIEFING.md
  • provenance-log.jsonl
  • feedback-queue.md entries
Tools
  • alxndr retrieve

Data Flow

How information moves through the system, from raw signal to builder context

Signal In
Raw information arrives: meeting notes, Slack threads, customer feedback, strategy docs, executive directives.
Solomon triages via 6 intake doors.
→ tension briefs → source material files → signal-queue.jsonl
↓
Construction
Settled claims become source material. Sam builds or updates cards. Nit lint-checks after every batch. Cards follow the build order: rationale → product → experience → temporal.
→ library cards (.md) → wikilink graph → folder structure
↓
Quality
Nit pre-sweeps (6 levels) → Conan grades (5D, A-F) → diagnoses root causes → Sam fixes → re-grade.
This is the most important play. The trunk of the tree.
→ grade reports → surgery plans → health reports → scoreboard
↓
Service
Bridget assembles context briefings for tasks. 15 retrieval profiles, U-shaped ordering, gap manifests. Raven conducts product conversations and planning.
→ CONTEXT_BRIEFING.md → implementation plans → outcomes + tickets → provenance-log.jsonl
↓
Factory
Builders (human or agent) receive context briefings and tickets. They implement features, fix bugs, build products.
Factory is OUTSIDE Alexandria. We deliver context to it; we don't run it.
→ shipped code → execution learnings → revised plans
↓ learns from ↓
Learn
Execution outcomes, builder feedback, briefing retrospectives, and provenance analytics feed back into the library.
This is the least mature motion. The feedback loop mostly exists on paper.
→ feedback-queue.md → library updates → retrieval tuning ↑ back to Quality
