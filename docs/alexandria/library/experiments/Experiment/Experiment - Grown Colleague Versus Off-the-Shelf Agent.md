## WHAT

Hand one real task, cold, to a colleague grown out of the company's own documented design and to an off-the-shelf agent with none of that grounding, compare the two results side by side, and repeat across a few more tasks inside a short window.

## WHY

The wager that a colleague grown from a company's own design is worth the work of growing it only holds if that grounding shows up in the quality of real work, not just in how using it feels. A head-to-head on real tasks is the cheapest way to see whether the grown colleague's output is actually better before the company invests further in the harder, later question of whether real directors value and pay for that difference.

## WHERE

It tests [[Bet - Colleagues Grown from Company Design]]. It is the value-side companion to the dogfooding already under way, which de-risks this bet's feasibility rather than its value; this probe is what checks whether a colleague grown this way is actually better at the work, not merely whether growing one is possible.

## WHEN

There is no past yet: N/A — no task has been run against both yet. In the present it is planned, its shape set — a real task, run cold, both sides compared without either being told what it is being tested against. What is intended next is that it runs across a few tasks inside a short, fixed window.

## HOW

The instrument is a blind, side-by-side comparison on real work: the same task is handed to both the grown colleague and the off-the-shelf agent, and the two outputs are compared without either being told which is being tested against which. A few tasks are run this way inside a short window, since this is a disposable first look rather than a metered study, and there is no target score, only the comparison itself and a stop once the window closes or a handful of tasks have run.
