## WHAT

The whole graph — the complete, organized set of knowledge being managed,
not a level in the containment hierarchy so much as the name for the
hierarchy's total contents. One division's Library is its full set of
Planes, and everything they hold in turn: Contexts, and the Atomic Cards
filed within them. The concept recurses one level up: a Company's
Library is the planned federation of all its divisions' libraries into
one.

## WHY

The Library makes concrete
[[Bet - Library as Living Source of Truth|the wager on a living source of truth]]
— the one place company knowledge accumulates instead of going stale
across scattered documents. It only works because what it holds is
atomized into cards a colleague can compose, not a pile of prose,
[[Bet - Atomic, Agent-Readable Knowledge|the wager on atomic knowledge]].
Naming the whole graph as one thing, with a fixed containment order
beneath it, is also what keeps a director able to find their way from
the root down to any single card, [[Principle - Legible Graph]].

## WHERE

The library root a workspace points at; the whole of what the Library
pillar in the viewer shows.

## HOW

A Library is a Domain's complete holdings: it contains
[[Entity - Plane|Planes]], which in turn hold Contexts and Atomic
Cards. One [[Entity - Domain]] has one Library; a
[[Entity - Company]] of several divisions has, in the federated future,
one Library per Domain plus the federation joining them. The worked
example is [[Entity - Alexandria Product Library]] — the concrete
instance this generic concept describes: Alexandria's own Product
division's library, today the only one built.
