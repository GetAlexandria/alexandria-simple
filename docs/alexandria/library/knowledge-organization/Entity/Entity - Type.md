## WHAT

Type is the product-descriptive classifying axis: which family a card
belongs to, or what kind of product-noun it is as a user meets it — an
entity, a mechanism, a capability, and so on. It is the primary axis a
card is classified by.

## WHY

Knowing what a card is before reading it is what turns a pile of atoms
into a graph a colleague navigates by kind — Type is the axis
[[Bet - Atomic, Agent-Readable Knowledge]] sorts by. Families are named
and fixed rather than invented ad hoc per card, so the vocabulary a
director learns once keeps working everywhere,
[[Principle - Legible Graph]].

## WHERE

Carried on every card in the library, alongside its other classifying
fields.

## HOW

Every [[Entity - Atomic Card]] carries one Type. A card's Type value comes
from the buckets defined in [[Entity - Atomic Card Category]]. Type is
orthogonal to [[Entity - Altitude]]: the two axes classify a card along
different, independent dimensions rather than competing to describe the
same thing.
