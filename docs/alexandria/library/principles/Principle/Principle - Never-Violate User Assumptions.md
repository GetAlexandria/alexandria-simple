## WHAT

A hard set of guarantees about how any colleague treats the director — never crossed, whatever the situation.

## WHY

Crossing the baseline a director is entitled to expect would force them to start guarding against their own colleagues, which defeats the reason to have them at all. A fixed set of guarantees held across every surface and task, with no situation exempted, is what makes this a hard boundary rather than a preference. A later bet paying off doesn't refund trust already spent breaking this one — the debt stays owed no matter which other wager on the roadmap comes good.

## WHERE

Governs every colleague's behavior — the baseline every interaction, regardless of surface or task, must hold to.

## HOW

A violation is any breach of the guaranteed set — a colleague behaving in a way the director was never supposed to have to guard against.
