## WHAT
_Stub —_ the sequenced production line a play traverses: nine steps (numbered 0-8 in README), two Director gates, six [[Value - Stage]] columns. Strictly ordered between gates — each step invalidates the next if skipped.

## WHERE
Authored as `studio/plays/README.md` "The loop" table. Materializes through every play's directory artifacts. Re-entered mid-line for big edits per [[Component - Big Edit Playbook]].

## WHY
"This is the front end the old factory never had." Earned hard: without it, agents wandered, prompts drifted, and the system relied on intent rather than verified behavior (autopsy).

## WHEN
Reshaped 2026-06-12 (Slice 2 of the Studio → Fabro plan) — the monolithic prompt step retired; Derive replaced it.

## HOW
Nine numbered steps:
0. **Ground** — [[Aggregate - Grounding Doc]] (Director + orchestrator + Sonnet researchers).
1. **Brief** — [[Aggregate - Brief]] (Director).
2. **Harden** — [[Aggregate - Hardening Record]] ([[Agent - Hardener]] + Director).
3. **Confirm the design** — [[Capability - Gate 1]].
4. **Derive** — [[Aggregate - Workflow Package]] + fixtures ([[Agent - Author]]).
5. **Lint** — [[Component - Lint Verdict]] ([[Agent - Checker]]).
6. **Dry-run** — [[Aggregate - Run Record]] ([[Agent - Grader]]).
7. **Confirm it's proven** — [[Capability - Gate 2]].
8. **Register** — package banked + `PLAY_MANIFEST` entry (orchestrator).
