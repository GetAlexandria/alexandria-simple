# Learning evidence map (2026-07-09)

This is the deferred tested-by pass for the Strategy and Learning planes. The
Strategy embodiment map left the evidence channel unwired until Learning cards
existed; those cards now exist, so this map is the single source for which
evidence links get written back into Bet cards and which Learning-card ties are
verified or tightened.

## Mechanism decisions

1. **Prose wikilinks only.** Bet cards name instruments in body prose. No
   `tests`, `informs`, `embodied_by`, or `embodied-by` frontmatter keys are
   introduced here.
2. **Map rows are the apply inventory.** Writers may drop a tie they cannot
   ground in the card's body, but may not add a card edit that is not listed
   here.
3. **Links resolve by card stem.** The apply pass uses noun-in-sentence
   wikilinks, with pipe aliases where the card stem would make the sentence
   clumsy.
4. **Evidence stays honest about grain.** Corporate Bets can cite the full
   adoption-plus-diagnostic instrument family. Product-level refractions cite
   the smallest current Learning card that actually watches, tests, or has
   moved that wager; where only a shelf-level or proxy instrument exists, the
   residual is named.
5. **Keystone proof lives in WHAT.** D10 proof clauses cite the golden Measure
   from the keystone `## WHAT` sections, never from a proof-only WHY section.
