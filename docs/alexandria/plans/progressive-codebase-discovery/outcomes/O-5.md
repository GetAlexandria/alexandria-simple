## Validation Criteria

- Token cost measured per scan tier (Tier 1 tree vs Tier 2 schema/routes)
- Escalation rate measured: how often does Tier 1 resolve without needing Tier 2
- Self-consistency measured: does Tier 1 find the same nouns as Tier 1 + Tier 2
- Metrics collected across 3+ codebases of varying size and tech stack

## Motivation

Progressive investigation is only valuable if it actually saves tokens without losing accuracy. These mechanical metrics can be automated against any codebase. They tell us whether the tiered approach is working or whether we should just do a full scan every time.
