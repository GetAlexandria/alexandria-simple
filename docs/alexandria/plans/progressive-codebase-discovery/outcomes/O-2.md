## Validation Criteria

- Scanner reads a codebase's file tree and identifies structural patterns (models, routes, components, modules)
- Tier 1 (tree) produces initial noun proposals from directory and file structure alone
- Tier 2 (schema/routes) deepens proposals with actual file content (model fields, route paths, component structure)
- Proposals are product-level nouns ("Billing", "Notifications", "User Profiles"), not implementation details ("DatabaseConnection", "BaseModel")
- Framework-agnostic heuristics work across common tech stacks (Python, JS/TS, Ruby, Go)

## Motivation

The codebase is the ground truth for what exists today. The scanner's job is structural — "what entities exist and how do they connect" — not behavioral. It proposes; the human confirms. Progressive investigation (tree first, schema second) controls token cost while maintaining accuracy.
