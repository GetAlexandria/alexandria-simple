## Validation Criteria

- Given existing docs + scanner output, divergences are detected and classified
- Three divergence types: missing-from-code, missing-from-docs, evolved-past-docs
- Divergences are presented to the user with evidence from both sources
- Only runs when user has both documentation and code (routing answer: both)

## Motivation

Documentation drifts from code reality. A product owner says "we have a notification system" but the code shows it was half-built and abandoned. Code walk closes this gap by comparing what docs claim against what code shows, giving the user a concrete list of where their documentation has drifted.
