## Validation Criteria

- Two yes/no routing questions ("Do you have existing product documentation?" / "Do you have code to scan?") correctly determine the input path
- Code-only users are routed to the scanner flow, not asked for docs they don't have
- Docs-only users proceed through the existing wizard unchanged
- Both-docs-and-code users get the scanner flow with doc validation available later

## Motivation

Today the wizard assumes users have documentation to provide. Code-first users — solo builders who shipped before writing docs — hit a dead end. Routing gives them an entry point by asking what inputs exist before asking configuration questions.
