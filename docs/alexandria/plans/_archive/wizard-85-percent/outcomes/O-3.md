## Validation Criteria

- After configuration summary (Step 4), the user sees a "does this ring true?"
  confirmation that surfaces Foundation area problems
- If the user says the problems sound unfamiliar, they can reconfigure without
  having to restart from scratch

## Motivation

Even with better questions, some users will miscalibrate. A cheap empirical check —
"do these problems sound familiar?" — catches mismatches before investing in gap
analysis. Non-systems-thinkers may answer Q3 wrong but can recognize symptoms when
they see them. This is a safety net, not a primary mechanism.
