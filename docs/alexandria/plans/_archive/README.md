# Plans Archive

Archived 2026-07-04 during the pare-back of `docs/alexandria/plans/`. This
directory holds shipped and historical plans, kept for reference — nothing
here is active.

Active plans live one level up, in `docs/alexandria/plans/` directly. The
directories that stayed there were judged to still be live work areas as of
the sweep date.

A plan can be promoted back out of `_archive/` (moved back up a level) if
work on it resumes.

Note: in-flight PRs authored before this sweep may still reference the old
`docs/alexandria/plans/<name>` paths for plans that moved here. If you follow
a stale link from an older PR or issue, look for the same directory name
under `_archive/` before assuming it no longer exists.
