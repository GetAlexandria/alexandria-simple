## Validation Criteria

- `bin/alxndr update-check` fetches `latest-version.txt` from `sociotechnica.org/alexandria/` instead of raw GitHub
- When an upgrade is available, the output includes the tarball download URL
- The upgrade skill displays the download URL to the user

## Motivation

Currently the update-check fetches VERSION from raw.githubusercontent.com, which
requires the repo to be public. Switching to `sociotechnica.org/alexandria/latest-version.txt`
aligns with the private-repo distribution model and gives users a direct download
link when an upgrade is available.
