## Validation Criteria

- `curl -fsSL https://sociotechnica.org/alexandria/install.sh | bash` downloads the latest tarball and installs the plugin
- Inside a git repo, the script installs to `<REPO_ROOT>/.claude/plugins/alexandria/`
- Outside a git repo, the script installs to `~/.claude/plugins/alexandria/`
- The script prompts for confirmation before installing, showing the target path
- If Bun is not installed, the script installs it automatically
- After installation, the plugin loads in Claude Code without a `--plugin-dir` flag

## Motivation

The install experience is the product's first impression. A one-liner that
auto-detects the right install path and handles dependencies removes friction
and makes Alexandria accessible to anyone with Claude Code. The
project-local default keeps plugin versions tied to repos, which matters for
teams.
