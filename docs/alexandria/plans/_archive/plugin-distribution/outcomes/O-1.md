## Validation Criteria

- A build script produces `alexandria-v{VERSION}.tar.gz` at ~1.2 MB
- The tarball excludes tests/, docs/design/, docs/adrs/, docs/plans/, docs/alexandria/, EVALS.md, .github/
- Extracting the tarball and running `./setup` produces a functional plugin that loads in Claude Code

## Motivation

The full repo is ~7.3 MB, of which ~6.1 MB is dev-only overhead. Users installing
the plugin don't need tests, design docs, ADRs, sample libraries, or project plans.
A stripped tarball makes the install lightweight and avoids shipping internal artifacts
to users of a product that may eventually be closed-source.
