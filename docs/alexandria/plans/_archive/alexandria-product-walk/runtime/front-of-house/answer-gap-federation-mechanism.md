Federation is planned product machinery, not yet realized. Today each project has one library root and no federation mechanism — the PMS pointer card is the only cross-library link.

The vision: multiple libraries managed by business units (marketing, sales, finance, operations, etc.) that link to each other, creating a library of libraries — a giant company library. Federation will mean libraries "talk to" each other through links. Not shipped yet; the current build is proving the single-library path first.

The Playmaker's Studio Library pointer card is correct as a reference to the federated library that exists by director ruling, not by product machinery.
