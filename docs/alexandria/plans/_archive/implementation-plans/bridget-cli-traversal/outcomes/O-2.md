## Validation Criteria

- A passing baseline for `bridget/assembly` is confirmed reproducible before any skill change.
- Post-wire run of `bin/alexandria-eval run bridget/assembly` produces scores ≥ baseline.
- Judge criterion 7 (retrieval profile adherence) does not regress.
- Updated baseline is checked in alongside the wiring change.
- If a regression occurs, root cause is identified as a CLI knob gap and queued as a follow-on plan rather than patched in the skill.

## Motivation

`Principle - Measure Before Promoting` requires baseline-then-change-then-compare for any modification to assembly mechanics. Criterion 7 is the primary signal that the CLI's profile knobs are sufficient; treating its regression as noise would silently degrade the thesis Bridget exists to deliver.
