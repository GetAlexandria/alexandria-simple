## Validation Criteria

- A table in `skills/context-briefing/task-modifiers.md` (or equivalent) maps each task type / modifier combination to specific `--profile` and `--complexity` values.
- The mapping is referenced from Bridget's protocol where the CLI is invoked.
- A reader can determine the CLI flags for any classified task without consulting Bridget's runtime judgment.

## Motivation

Bridget's context briefing identifies this as the highest-risk gap: the skill files describe traversal behaviors in prose, but mapping them to `alxndr retrieve` flags is implicit. If the mapping is wrong at runtime, criterion 7 regresses with no obvious diagnosis. Making the mapping explicit converts a silent failure mode into a reviewable artifact.
