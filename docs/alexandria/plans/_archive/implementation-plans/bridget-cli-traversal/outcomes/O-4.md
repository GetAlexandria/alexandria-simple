## Validation Criteria

- If the eval gate exposes a missing profile knob (hops, direction, lateral scope, budget tier), a root-cause note names the specific knob and the criterion it affects.
- A follow-on plan or issue is filed against the CLI, not patched into Bridget's skill.
- Bridget's skill files do not gain a workaround that re-introduces agentic traversal to compensate.

## Motivation

The deterministic middle is only useful if it stays deterministic. The first time a missing knob is patched into the skill instead of the CLI, the layer boundary has been violated and the migration's value erodes. This outcome makes "surface, don't paper over" the explicit posture.
