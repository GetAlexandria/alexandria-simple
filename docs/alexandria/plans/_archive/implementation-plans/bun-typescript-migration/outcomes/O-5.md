## Validation Criteria

- `./setup` produces compiled binaries in `bin/.compiled/` via `bun build --compile`
- Plugin consumers can run all 11 TypeScript-backed CLI tools without Bun or Node.js installed
- Binary size is documented and accepted against measured reality
- Setup script detects missing Bun and provides install instructions

## Motivation

Following gstack's proven pattern. Plugin consumers install via symlinks and
should not need any JavaScript runtime. Compiled binaries make the TypeScript
migration transparent to end users — the tools work exactly as before, just
faster and with better error messages.

## Compiled Tool Surface

The compiled distribution contract covers these public wrappers:

- `alxndr dag`
- `alexandria-eval`
- `alxndr grade`
- `alxndr lint`
- `alexandria-retrieve`
- `alexandria-route`
- `alexandria-sync-issues`
- `alexandria-tensions`
- `alxndr update-check`
- `alxndr version`
- `alexandria-initialize`

## Measured Binary Sizes

| `alexandria-eval` | 59 MB |
| `alxndr grade` | 58 MB |
| `alxndr lint` | 59 MB |
| `alexandria-retrieve` | 59 MB |
| `alexandria-route` | 59 MB |
| `alexandria-sync-issues` | 59 MB |
| `alexandria-tensions` | 59 MB |
| `alxndr update-check` | 58 MB |
| `alxndr version` | 58 MB |

The earlier provisional target of “under 50 MB per tool” did not hold for the
actual Bun compiled artifacts. Current acceptance is that the binaries are
roughly `58-59 MB` each on macOS, and that size is documented explicitly rather
than treated as a hidden regression.
