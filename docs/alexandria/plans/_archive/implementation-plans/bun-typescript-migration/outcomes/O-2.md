## Validation Criteria

- `bun test` runs all unit and QA tests from a single command
- Test count is equal to or greater than the current 170+ tests
- No bash test scripts remain in `tests/` (except eval-case fixtures)
- CI runs `bun test` as the validation step
- Tests ported BEFORE their corresponding tools are rewritten

## Motivation

The current 16 test suites are 6,286 lines of bash with hand-rolled assertion
helpers. Porting to `bun test` first — while tests still call Python/bash tools —
creates the safety net for the entire migration. A test that passes against Python
and then passes against TypeScript proves behavioral equivalence.
