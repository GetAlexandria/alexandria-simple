## Validation Criteria

- Every script in `bin/` is a TypeScript source file executed via Bun
- `bun build --compile` produces standalone binaries that run without Bun installed
- All existing CLI contracts (flags, exit codes, output formats) are preserved
- No bash or Python scripts remain in `bin/`
- All 11 tools: dag, eval, grade, lint, retrieve, route, sync-issues, tensions, update-check, version, wizard

## Motivation

The CLI tools are the primary user-facing interface to Alexandria's
infrastructure. 7 are Python, 4 are bash. Migrating to TypeScript gives type
safety, shared modules, and a single language. Compiled binaries via
`bun build --compile` ensure end users don't need Bun installed.
