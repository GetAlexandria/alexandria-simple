## Validation Criteria

- Single-prompt, multi-turn, and adaptive LLM-as-user modes all produce identical results to the bash harness
- Structural checks run as TypeScript functions (colocated with eval cases)
- LLM-as-Judge scoring produces equivalent categorical results
- Transcript format is unchanged
- Eval baselines from before migration still compare cleanly

## Motivation

The eval harness is the most critical system in the tooling layer. It gates
all skill changes via the "measure before promoting" principle. Breaking eval
capability during migration would stall all skill development. The harness
must work identically after migration.
