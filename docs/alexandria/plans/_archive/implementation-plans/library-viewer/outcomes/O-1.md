## Validation Criteria

- A user can open the viewer in a browser and see any library card rendered as HTML
- Card pages display all five dimensions (WHAT, WHERE, WHY, WHEN, HOW) as distinct visual sections
- Wikilinks (`[[Type - Name]]`) render as clickable links that navigate to the target card page
- Wikilink context phrases display inline alongside the link text
- Broken wikilinks (target card does not exist) are visually distinguished from resolved links

## Motivation

The library has ~190 cards with rich wikilink relationships, but no human-browsing
surface exists today. All interaction is through AI agents or CLI tools. Rendering
cards as navigable HTML with working wikilinks is the foundational capability that
makes the library accessible to humans for the first time.
