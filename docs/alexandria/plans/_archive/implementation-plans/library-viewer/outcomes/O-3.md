## Validation Criteria

- A left sidebar displays the library's folder hierarchy as a navigable tree
- Top-level groups correspond to layers (rationale, product, experience)
- Type-plural subfolders appear as expandable tree nodes under each layer
- Individual cards appear as leaf nodes under their type folder
- Clicking a card name in the sidebar navigates to that card's page
- The current card is highlighted in the sidebar

## Motivation

The library's folder structure encodes the type taxonomy. The sidebar tree makes
this structure visible and navigable, serving as the primary wayfinding mechanism.
Without it, users have no way to discover what cards exist or how they're organized.
