## Validation Criteria

- The landing page displays total card count, type distribution, and layer distribution
- Broken link count and orphan card count are prominently shown as health indicators
- Link density metric is displayed to indicate graph connectedness
- Type distribution is visualized (chart or table) showing count per type
- Each metric links to the relevant detail view (e.g., clicking broken links shows the list)

## Motivation

A dashboard gives library maintainers an at-a-glance view of the library's health
and completeness. The graph parser already computes these metrics; the dashboard
makes them visible without running CLI tools. This supports the "Structural Quality
Before Functional Quality" principle by surfacing structural health first.
