## Validation Criteria

- Running `bin/alexandria-viewer` starts a local Astro dev server on a configurable port
- The server watches markdown files in `docs/alexandria/` and regenerates pages on change
- Running `bin/alexandria-viewer build` produces a static HTML export in a dist directory
- The CLI follows the existing Alexandria wrapper pattern (resolves plugin root, falls back to bun run)

## Motivation

The viewer must be a deterministic tool that humans can run without an agent. A CLI
entry point that starts a dev server with file watching lets library authors see
their changes in real time. Static build mode enables sharing the rendered library
or hosting it in CI artifacts.
