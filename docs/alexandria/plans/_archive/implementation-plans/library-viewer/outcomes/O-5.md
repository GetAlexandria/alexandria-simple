## Validation Criteria

- A dedicated Plans section lists all implementation plans from `docs/alexandria/implementation-plans/`
- Each plan shows its release.md rendered as the plan overview page
- Outcome files (`O-*.md`) are listed and linked from the plan page
- Ticket files (`FEAT-*.md`, `SPIKE-*.md`, `PROTO-*.md`) are listed and linked from the plan page
- Plan status (from release.md frontmatter) is visible in the plan list

## Motivation

Implementation plans are a key part of the library but have a different structure
from library cards. They need their own rendering logic that presents the
release-outcomes-tickets hierarchy as a coherent view, making it easy for humans
to understand what was planned, what was built, and what was deferred.
