## Validation Criteria

- `ax cards --help` prints a complete usage summary including all subcommands, flags, and their semantics
- `ax cards list --help` prints flag-level help for the list subcommand
- Future flags such as `--area` are not documented until their horizontal slice lands
- Help output is consistent with the conventions used by other `ax` subcommands (e.g., `ax dag --help`, `ax lint --help`)

## Motivation

The CLI is meant to replace a hand-maintained markdown file as the surface
agents and humans consult for inventory queries. If the surface is not
self-documenting, callers (especially Conan) need a separate teaching pass
to know what to invoke and what flags exist.

This outcome is `Could` tier — Phase 1 ships even without it — but it is cheap
polish that pays back every time a new agent or human needs to learn the
surface. The cost is roughly half a day of work plus tests; the benefit is
"Conan's prompt can be taught by reference, not by re-explanation."
