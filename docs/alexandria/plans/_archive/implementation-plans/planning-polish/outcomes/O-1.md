## Validation Criteria

- Every `SKILL.md` `name:` field uses a short descriptive name (no manual prefixing)
- Skills are invocable as `/alexandria:<name>` via Claude Code plugin auto-namespacing
- `context-library-upgrade` compatibility alias is removed
- `release` skill is moved to `contributor-skills/` (repo-maintainer workflow, not product surface)
- No agent or skill files reference removed/renamed invocation targets
- `bun test` and `bun run check` pass with no broken references

## Motivation

Alexandria's skill surface is the primary user interface for the plugin. Before
preview release, skill names must be clean, short, and consistent. Claude Code's
plugin auto-namespacing means skills are already prefixed as `/alexandria:<name>`,
so the `name:` field should be a simple descriptor, not a long hyphenated slug.
Removing the compatibility alias and relocating internal-only skills keeps the
product surface focused on what end users need.
