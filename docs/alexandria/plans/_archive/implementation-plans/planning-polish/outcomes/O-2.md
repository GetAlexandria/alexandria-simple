## Validation Criteria

- New skill exists at `skills/sync-tickets/SKILL.md`
- Skill wraps the existing `bin/alexandria-sync-issues` CLI tool
- Skill procedure includes dry-run preview, user confirmation, execution, and results reporting
- Skill is invocable as `/alexandria:sync-tickets`
- Implementation planning Step 9 mentions the skill (covered by O-3)
- `bun run check` passes

## Motivation

The `bin/alexandria-sync-issues` CLI tool already syncs implementation plan
tickets to GitHub issues, but it requires manual invocation with the correct
arguments. Wrapping it as a skill makes it discoverable and agent-invocable,
closing the gap between planning and execution. Users who just finished planning
can sync tickets without leaving the conversation.
