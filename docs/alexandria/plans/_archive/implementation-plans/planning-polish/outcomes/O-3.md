## Validation Criteria

- Step 9 summary in `skills/implementation-planning/SKILL.md` includes a prompt to run `/alexandria:sync-tickets`
- The prompt is informational (user chooses whether to sync), not enforced
- `bun run check` passes

## Motivation

Planning and ticket sync are naturally sequential workflows. After writing plan
files, users often want to create GitHub issues from those tickets. Mentioning
`/alexandria:sync-tickets` in the planning skill's summary step makes the
workflow discoverable without forcing it. This is the "front-load value"
principle in action: surface the next step when the user is most likely to want
it.
