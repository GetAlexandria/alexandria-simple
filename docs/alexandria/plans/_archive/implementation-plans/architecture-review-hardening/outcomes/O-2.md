## Validation Criteria

- `alxndr lint` includes grade-evidence reconciliation (link counts vs WHERE grades, example counts vs HOW grades)
- `alxndr lint` includes briefing compliance (mandatory categories, card budget, provenance logged)
- `alxndr lint` includes design doc count verification (claimed counts match reality)
- `alxndr lint` includes conformance checking (product-layer cards link to governing Standards)
- `alxndr lint` includes internal consistency (YAML vs table/list count/set comparisons)
- `alxndr lint` includes downstream sync deviation detection (meta-files match reference.md)

## Motivation

These L6 checks are currently "manual" — performed agentically by Nit reading files. But they're all deterministic: counting links, comparing sets, validating schemas. Making them software eliminates the last reason for Nit to exist as an agent and makes health checks dramatically cheaper.
