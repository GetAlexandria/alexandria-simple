## Validation Criteria

- Every structural check previously performed agentically by Nit is available as an `alxndr lint` subcommand
- Agents in plays call `alxndr lint` instead of dispatching Nit for mechanical checks
- No agentic interpretation is required for structural/mechanical checks (link counts, section existence, frontmatter validation, etc.)

## Motivation

Mechanical checks done by an LLM agent are slow, expensive, and unreliable. The same checks done by deterministic software are instant, free, and perfectly consistent. This is the foundation everything else builds on — Nit retirement, simplified plays, and cheaper health checks all depend on the lint CLI being comprehensive.
