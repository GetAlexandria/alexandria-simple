## Validation Criteria

- `/wizard` is no longer a user-invocable slash command
- `/library` detects first-time setup (no alexandria-config.json) and triggers setup automatically
- Return visits to `/library` get the concierge greeting (state read + nudge + open invitation)
- All wizard functionality is preserved as an internal sub-procedure of `/library`

## Motivation

Having both `/wizard` and `/library` confuses users about which to run. The setup experience should be invisible — you knock on the library door, and if there's no library, setup happens. If there is, Raven greets you. One door, not two.
