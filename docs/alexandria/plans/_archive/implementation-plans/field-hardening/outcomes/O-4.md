## Validation Criteria

- **Top-1 shape:** when one next move is clearly strongest, Raven surfaces it alone with an open invitation. No parallel-menu alternatives.
- **Bounded-choice shape:** when multiple reasonable paths exist, Raven presents them via `AskUserQuestion` (or the host's multi-choice UI), each option framed as an action.
- **Sectional shape:** multi-group interviews walk one section at a time, not 21-at-once.
- Eval cases assert each shape: top-1 case has no alternatives, bounded-choice case uses multi-choice UI, sectional case walks groups sequentially.
- Library anchor cards exist: `Standard - Top-1 Surfacing Rule`, `Standard - Raven Concierge Greeting`.
- Host-capability fallback (per SPIKE-002) handles environments without `AskUserQuestion`.

## Motivation

Bryan's two specific complaints — "a lot of choices, but I have to pick only one thing" and "let's go through these 5 things: 1, 2, 3, 4, 5. Let's start with #1" — point at a single underlying failure: Raven dumps the full option set on the user and makes them reconstruct the sequence. The fix is three distinct shapes for three distinct situations: top-1 nudge when there's a clear winner, bounded-choice UI when there are real forks worth the user's judgment, sectional walk when the work is a multi-step interview. Together these replace the cold 21-question menu and the "run Agent A or B" parallel prompts with action-oriented control the user can actually exercise.
