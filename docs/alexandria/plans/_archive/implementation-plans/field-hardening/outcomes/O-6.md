## Validation Criteria

- Raven skill files contain no internal-vocabulary tokens in default user-facing prose: no F-codes (`F1`, `F6 promotion`), no agent-role nouns (Sam / Conan / Solomon / Bridget) outside orchestration-internal contexts, no tier shorthand (`Amplifier` / `Foundation` as bare terms without explanation).
- User-facing surfaces in other agents (any direct prose that reaches the user) match the same rule.
- Library cards that users read directly (e.g., onboarding-facing cards) have been voice-audited for the same tokens.
- An eval suite verifies forbidden-vocabulary doesn't leak across a representative set of flows, with coverage breadth documented in the eval README.

## Motivation

Jess told Bryan: "the language is very overfit to the way Danvers and I talk about things." The internal vocabulary — F-codes, "promotion," type names like "Amplifier," agent roles — is load-bearing for Alexandria's builders but opaque to users. This outcome is tiered Could because it's forever-work: voice regressions happen continuously and the audit needs to run as a sweep plus an eval rather than a one-time fix. Scope includes Raven skills, all user-facing output paths, and library card prose; evals are extensive and part of the deliverable.
