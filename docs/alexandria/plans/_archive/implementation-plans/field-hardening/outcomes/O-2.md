## Validation Criteria

- On a fresh `/library` session, Raven (via Sam under the curtain) drafts every card for which enough source material exists before surfacing unblock questions.
- Bryan-scenario eval case: given his captured intake, the session produces at least a Foundation-tier card set prior to the question list.
- Sam eval regression: draft-first behavior holds across representative scenarios without reducing final card quality scores.
- No user-facing beat asks more than one question before at least one card is drafted, when any draftable material exists.

## Motivation

Bryan's first `/library` session confronted him with 21 interview questions grouped into 5 blocks before any card was written. He couldn't tell which questions mattered, and the session felt like interrogation rather than collaboration. Jess already signaled the fix verbally ("write the cards, then unblock") but no commit supports it. Drafting with whatever information is already available — then surfacing unblock questions against the draft — converts the room from intake to review, which is a faster, calmer shape for the user and produces stronger evidence for the cards that remain.
