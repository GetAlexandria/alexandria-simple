## Validation Criteria

- Raven can update one Vision slot from the CLI/runtime path.
- The Web UI reflects Raven-written slot content as `needs_review`.
- The user can approve, skip, or edit Raven's slot text in the Web UI.
- Raven can observe the user's feedback through projected state or ledger events before continuing.
- Adding another source during review does not reset existing slot state.

## Motivation

The important prototype mechanic is not just a form. It is Raven participating while the user reviews her work. This outcome preserves the CLI/Web collaboration loop: Raven writes, the user reviews, Raven continues with the current state.
