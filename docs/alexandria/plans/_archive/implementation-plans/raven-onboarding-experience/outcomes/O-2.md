## Validation Criteria

- `Power up Raven: Vision` opens a Vision onboarding surface with nine slot cards.
- Users can always manually type or edit slot text.
- Each slot can move through `empty`, `needs_review`, `approved`, and `skipped`; skipping clears text and can be reopened.
- `ready_to_bank` is computed from slot state, not manually toggled.
- Source adding from Vision creates real shared source items, not Raven-specific inputs.
- Slot and source state survive reload and are visible from the CLI/runtime state.

## Motivation

Vision is the first Raven power-up. It needs to feel like a usable workflow, not a giant wizard step. Manual review is not a fallback; it is a permanent way for users to collaborate with Raven and correct the product context that powers later plays.
