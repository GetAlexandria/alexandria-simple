## Validation Criteria

- First-time Home shows the bottom agent shelf without presenting Raven as top-level navigation.
- Raven's coin has distinct inert and connected visual states driven by the runtime connection projection.
- Home shows `Connect Raven` before connection and `Power up Raven: Vision` after connection.
- Clicking Raven's coin opens a Quick Bar with Raven-specific actions.
- The Web UI and CLI state agree about whether Raven is connected and what first action is available.

## Motivation

The first onboarding beat should be simple: Alexandria is waiting for Raven, then Raven is connected and ready to be powered up. The prototype hid this behind modal/overlay behavior and logo-as-home navigation. This outcome makes the first screen obvious and gives Raven a home on the agent shelf instead of in the app's top-level navigation.
