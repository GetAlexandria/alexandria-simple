## Validation Criteria

- `/library` skill is registered and discoverable in Claude Code
- Invoking `/library` routes to Raven with wizard-mode job context loaded
- Raven opens with the first-five-minutes sequence (introduction, value exchange, handshake) — not a form or step-numbered procedure
- The skill file is a thin entry point; orchestration logic lives in Raven's agent definition
- Existing `/wizard` skill continues to work (no regression for CI/scripted paths)

## Motivation

The entire Phase 2 user experience depends on `/library` as an entry point. It is the door through which every `/library` session begins — first-time and returning alike. Getting this entry point right (thin, readable, routing cleanly to Raven's wizard-mode job) is prerequisite for every other outcome in this plan.

The skill surface deliberately does no orchestration itself. Its job is to invoke Raven with wizard-mode context. All session logic — scoreboard, conversation, agent delegation — lives in Raven's agent definition. This keeps the entry point stable even as the wizard-mode job evolves.
