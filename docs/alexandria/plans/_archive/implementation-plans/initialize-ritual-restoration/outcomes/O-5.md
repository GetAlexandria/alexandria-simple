## Validation Criteria

- First-session job calls `alxndr scoreboard derive <path> | alxndr scoreboard` after engine run to display a real scoreboard
- Returning-session job calls the same CLI during session-start orientation
- No Raven instruction references the scoreboard without calling the CLI

## Motivation

The `alxndr scoreboard derive` CLI already ships (`src/tools/scoreboard-derive.ts`, registered as an `alxndr` subcommand) but is not wired into any skill or agent. Every existing procedure reference to the scoreboard is partially aspirational — Raven currently derives it agentically via Glob/Grep/Read when it renders at all. Wiring the CLI into both init jobs turns the scoreboard into a real surface the procedures can rely on, and removes a source of drift between what the procedures claim and what happens.
