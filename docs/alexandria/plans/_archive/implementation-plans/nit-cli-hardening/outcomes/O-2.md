## Validation Criteria

- `skills/conan/job-health-check.md` instructs Conan to run `alxndr health-check <path>` before the assessment begins
- Conan uses structured JSON from the CLI for inventory reconciliation and Standards structural sub-checks
- Later judgment-heavy assessment steps remain Conan's exclusive LLM work
- If the CLI is unavailable, the health check still works (graceful degradation documented in skill)

## Motivation

Conan currently spends LLM context on work a CLI can do deterministically. Inventory reconciliation is a file-existence check. Standards health includes countable structural sub-checks (link counts, anti-example presence). By pre-computing these, Conan focuses LLM budget on judgment — the work only he can do.
