## Validation Criteria

- `alxndr lint lines` checks tab indentation (spaces only) and fenced code block language tags
- `alxndr lint lines` checks terminology consistency against known variant spellings
- `alxndr lint layers` checks manifest reconciliation (fidelity, cross-references, conformance map, enumeration drift)
- `alxndr lint library` runs terminology sweep across all cards
- Each new check has deterministic tests

## Motivation

These are real gaps in the existing sweep coverage identified during the Raven analysis. They're lower priority than sweep 6 and the CLI consolidation, but filling them makes the linter genuinely comprehensive.
