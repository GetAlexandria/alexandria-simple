## Validation Criteria

- `alxndr lint all <path>` runs all 11 lint targets (lines, cards, graph, layers, library, paths, plans, wizard, counts, grades, briefings) and exits 0/1
- Each lint target is individually invocable: `alxndr lint cards <path>`, `alxndr lint wizard <path>`, etc.
- Former sweep 6 checks (paths, plans, wizard, counts, grades, briefings) produce findings in the existing `Finding` schema with appropriate severity levels
- All new lint targets have deterministic tests
- Existing sweeps 1-5 behavior unchanged (no regressions)

## Motivation

The lint CLI already covers sweeps 1-5 mechanically. Sweep 6 (cross-system checks) is entirely absent and currently requires LLM work via Nit-the-agent. Adding these deterministic checks to the CLI means 100% exhaustive mechanical coverage at zero LLM cost, fulfilling the "software-ification" thesis from Decision 7.
