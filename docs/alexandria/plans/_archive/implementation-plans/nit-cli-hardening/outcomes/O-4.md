## Validation Criteria

- Single `alxndr` entry point dispatches to subcommands: `lint`, `health-check`, `grade`, `dag`, `version`, `update-check`
- `alxndr health-check <path>` emits structured JSON organized by Conan's health-check phases
- `alxndr grade`, `alxndr dag`, `alxndr version`, `alxndr update-check` work identically to their former `bin/alexandria-*` counterparts
- The 5 migrated `bin/alexandria-*` wrapper scripts are deleted (lint, grade, dag, version, update-check)
- All references (CI, agents, skills, CLAUDE.md, README, tests) updated to use `alxndr` commands
- Output contracts (exit codes, JSON schemas, text formats) are documented

## Motivation

The `bin/alexandria-*` scripts (12 total) with bash wrapper shims are hard to discover and maintain. This plan migrates 5 of them (lint, grade, dag, version, update-check) under a unified `alxndr` CLI that is distributable, self-documenting (`alxndr --help`), and positions Alexandria's tooling as a coherent product. The remaining 7 tools migrate in a future plan.
