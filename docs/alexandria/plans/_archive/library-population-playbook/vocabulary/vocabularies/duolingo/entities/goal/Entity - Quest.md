# Quest

## WHAT: Definition

_Stub — a named goal with completion criteria and a time bound. Quests subdivide into Daily Quests (time-bound to the day, solo, e.g., "Complete 3 Lessons") and Friend Quests (time-bound to the week, requiring a paired Friend, e.g., "Earn 200 XP together with a Friend"). Completion awards XP or Gems depending on Quest type._

_Naming-history note: "Quest" is borrowed from RPG vocabulary, consistent with the families.md gaming-family finding that game-shaped products can borrow RPG nouns where the player audience already recognizes them. The term is cleanly aesthetic-named — it describes the felt encounter (a named challenge to accept and complete), not a mechanism. Per the [[Standard - Duolingo Nomenclature Signature]], this borrowing is an RPG term, not an invented term — borrowed vocabulary is acceptable; invented vocabulary requires exceptional justification (and historically gets retired, as Lingot was)._
