# Section

## WHAT: Definition

_Stub — the coarsest grouping inside a Course. A Section contains multiple Units organized around a broad proficiency or topic area. The vocabulary is borrowed directly from classroom and textbook convention — per the [[Standard - Duolingo Nomenclature Signature]]'s pedagogy-borrowing rule. Learners recognize "Section" without onboarding because it maps to their existing experience of structured learning._
