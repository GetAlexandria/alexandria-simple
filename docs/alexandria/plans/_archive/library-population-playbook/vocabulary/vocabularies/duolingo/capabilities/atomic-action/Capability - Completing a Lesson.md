# Completing a Lesson

## WHAT: Definition

_Stub — the atomic learning action in Duolingo. A Learner completes a Lesson by finishing all exercise items in the sequence without running out of Hearts. Completion awards XP, advances Path progress, and counts toward Daily Quest and Goal tracking. Wrong answers deplete Hearts; running out of Hearts before completion ends the Lesson without awarding XP (free tier) or prompts a Heart refill option._
