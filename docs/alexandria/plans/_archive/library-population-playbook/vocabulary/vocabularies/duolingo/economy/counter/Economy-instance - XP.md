# XP

## WHAT: Definition

_Stub — the points awarded to a Learner for completing Lessons, Stories, and practice sessions. XP accumulates into the Learner's weekly total, which determines Leaderboard ranking within the current League cohort. XP also tracks against the Learner's daily Goal and contributes to Quest progress. XP is never spent — it is a pure scoring and ranking resource, not a currency._

## WHERE: Ecosystem

_Stub — links to: [[System - XP System]] (the engine that awards XP), [[Economy-instance - League]] (weekly XP drives League ranking), [[Entity - Quest]] (Quest completion criteria are often XP-based), [[Surface - Leaderboard]] (XP ranking is displayed on the Leaderboard), [[Surface - Profile]] (lifetime XP is displayed on the Learner's Profile)._
