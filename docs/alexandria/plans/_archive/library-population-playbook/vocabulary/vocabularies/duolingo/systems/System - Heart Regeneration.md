# Heart Regeneration

## WHAT: Definition

_Stub — the mechanism that decrements Hearts on wrong answers during a Lesson and regenerates them over time or via Gem spend or Super subscription. The Heart Regeneration system imposes a daily attempt budget on free-tier Learners; Super removes the cap. The system serves as the primary Conversion pressure on the free tier: Learners who run out of Hearts mid-day encounter the tier gate directly._

_Naming-history note: Duolingo has experimented in some markets with renaming this system "Energy," using a battery metaphor rather than a life-count metaphor. The Energy experiment is in-flight as of this writing — some regions see the battery UI; the canonical product noun remains Hearts. This is an active naming experiment, not a settled deprecation. If you encounter "Energy" in Duolingo documentation or market-specific designs, it refers to the same underlying system with a different aesthetic metaphor. Tag accordingly: the [[Standard - Duolingo Nomenclature Signature]] would flag any Hearts → Energy rename as a signature-level decision (the Heart is felt-experience-named; Energy is a metaphor that requires more explanation)._
