# Weekly League Cycle

## WHAT: Definition

_Stub — the Sunday-reset competitive cycle that governs League promotion and relegation. Each week, a Learner is placed in a cohort of approximately 30 Learners in the same League tier. The cohort competes by XP earned during the week. At reset (Sunday), Learners who finish in the top positions are promoted to the next League tier; Learners who finish in the bottom positions are relegated. The tier ordering runs: Bronze → Silver → Gold → Sapphire → Ruby → Emerald → Amethyst → Pearl → Obsidian → Diamond → Diamond Tournament (the top competitive tier)._
