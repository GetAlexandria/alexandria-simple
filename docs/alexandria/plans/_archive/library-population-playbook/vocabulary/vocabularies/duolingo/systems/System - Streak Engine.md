# Streak Engine

## WHAT: Definition

_Stub — the mechanism counting consecutive-day participation, determining whether the day's activity met the Streak-maintenance threshold, awarding Streak milestone rewards, and triggering Streak loss when a day passes without qualifying activity. The Streak Engine is the system; [[Economy-instance - Streak]] is the user-facing noun the Engine maintains._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Streak]] (the user-facing noun this Engine produces), [[Economy-instance - Streak Freeze]] (the meta-resource that prevents Streak loss when the Engine would otherwise decrement), [[Pattern - Daily Engagement Loop]] (the Loop is built substantially around the outputs of the Streak Engine), [[Pattern - Streak Recovery]] (the recovery Pattern triggered when the Engine records a loss)._
