# Path

## WHAT: Definition

_Stub — the home-screen lesson sequence the Learner walks through a Course. The Path renders as a winding vertical trail of nodes (each node is a Lesson or a milestone marker); the Learner completes nodes in sequence, advancing along the trail. The Path is both an Entity (the object that represents Course progress) and a Surface facet (the home-screen display mode) — see [[Surface - Home]]._

_Naming-history note: the Path replaced the older "Skill Tree" UI in the 2022 redesign. The Skill Tree allowed free selection of any unlocked Skill in any order; the Path is linearized with fewer branching choices. The rename was deliberate and signals a design philosophy shift — from a browsable topic catalog to a guided sequence. The Crown system's per-Skill mastery levels were retired in the same redesign, because the per-Skill model assumed the non-linear tree navigation that the Path abandoned. See [[Deprecation - Crown]] for that migration context. This is the canonical case of Duolingo using a noun change to signal a product-philosophy change: Tree → Path communicates "we're no longer letting you wander."_
