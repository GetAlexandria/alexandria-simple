# Listening

## WHAT: Definition

_Stub — audio-driven exercise type in which the Learner hears speech in the target language and responds (transcribes, translates, or selects the heard phrase). Listening exercises appear within Lessons, Stories, and DuoRadio. One of several modality-specific Capabilities; the others include Speaking, Reading, and Translation._
