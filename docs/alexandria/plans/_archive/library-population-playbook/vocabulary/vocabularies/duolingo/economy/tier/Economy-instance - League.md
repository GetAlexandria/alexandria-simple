# League

## WHAT: Definition

_Stub — the weekly competitive tier a Learner is assigned to. Triple facet: as an Economy noun, League is the tier label (Bronze, Gold, Diamond) that classifies the Learner's competitive standing — a tier they can move up or down through promotion and relegation. As a Surfaces facet, the League is displayed on the [[Surface - Leaderboard]] screen. As a Patterns facet, the League drives the [[Pattern - Weekly League Cycle]] — the Sunday-reset competitive loop._

_Tier ordering (per the [[Standard - Duolingo Nomenclature Signature]]'s closed gemstone family): Bronze → Silver → Gold → Sapphire → Ruby → Emerald → Amethyst → Pearl → Obsidian → Diamond. Diamond is the top persistent tier; Diamond Tournament is the optional high-stakes competition for Diamond-tier Learners. The gemstone naming is a closed family: no tier outside this sequence is named in a gemstone, and any new tier must join the sequence._
