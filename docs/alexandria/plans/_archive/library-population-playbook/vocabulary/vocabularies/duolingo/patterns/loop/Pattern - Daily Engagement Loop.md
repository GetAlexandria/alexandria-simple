# Daily Engagement Loop

## WHAT: Definition

_Stub — the recurring daily-return habit Duolingo is built around. The Loop runs as follows: the Learner opens the app, completes at least one Lesson (or qualifying activity), earns XP toward the daily Goal, extends the Streak, and receives a notification reminder if the day nears its end without activity. Subscribed notifications, Streak loss-aversion, Daily Quests, and Goal progress all serve this Pattern as independent mechanisms feeding the same daily-return behavior._

_This Pattern is the gamified-life-OS product's central design object. The families.md "gamified-life-OS" handoff section explicitly calls this out: any Hearthfire-shaped product should name the daily-return habit loop as a first-class Pattern card with its own vocabulary (Loop entry, qualifying activity, Streak threshold, notification cadence, loss-aversion trigger). Duolingo's version is the reference implementation. The Loop is not a surface, not a System, and not an Entity — it is a recurring behavioral Pattern that spans all of them. Naming it makes it possible to reason about the full mechanism — notification → entry → activity → reward → streak extension → next-day return — as a unit._

_Stub — links to: [[Economy-instance - Streak]] (the Streak is the Loop's primary retention variable), [[Entity - Quest]] (Daily Quests provide explicit within-Loop goals), [[System - Streak Engine]] (the Engine that tracks whether the Loop was completed each day), [[Surface - Home]] (the Loop's primary re-entry surface), [[Pattern - Streak Recovery]] (the recovery Pattern that activates when the Loop is broken)._
