# Course

## WHAT: Definition

_Stub — the top-level container in Duolingo. A Course is a language pair (English→Spanish, Spanish→French, etc.) that contains all Sections, Units, and Lessons for one learning direction. A Learner may be enrolled in multiple Courses simultaneously. The Course is Duolingo's Workspace-equivalent: the billing and progress boundary within which all other entities live._
