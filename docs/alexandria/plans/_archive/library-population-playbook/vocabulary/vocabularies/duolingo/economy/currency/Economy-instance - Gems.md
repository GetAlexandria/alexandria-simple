# Gems

## WHAT: Definition

_Stub — the in-app currency. Earned via Streak milestones, Lesson completion (in some contexts), and occasional event rewards; purchased directly with real money via the Shop. Spent in the Shop on Streak Freezes, Streak Repairs, Heart refills, and cosmetic items. Gems are the closed-loop currency — there are explicit sources (earn/buy) and explicit sinks (Shop purchases)._
