# Lesson

## WHAT: Definition

_Stub — the atomic learning activity inside a Unit. A Lesson takes a few minutes, contains a sequence of exercises across modalities (Listening, Speaking, Reading, translation), and awards XP on completion. Hearts are depleted by wrong answers during a Lesson. Textbook vocabulary borrowed per the [[Standard - Duolingo Nomenclature Signature]]'s pedagogy-borrowing rule._
