# Unit

## WHAT: Definition

_Stub — the sub-section inside a Section. A Unit focuses on a specific communication goal (e.g., "Order food," "Describe your home," "Talk about travel"). A Unit contains multiple Lessons. Like Section, the vocabulary is borrowed from textbook convention per the [[Standard - Duolingo Nomenclature Signature]]'s pedagogy-borrowing rule._
