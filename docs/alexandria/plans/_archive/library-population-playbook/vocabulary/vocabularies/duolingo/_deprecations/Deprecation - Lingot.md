# Deprecation - Lingot

## WHAT (the tombstone)

_The currency Duolingo used before Gems. Retired roughly 2018 when the company migrated to "Gems" as a more universally recognizable currency name. Existing user balances ported 1:1._

_Per the families.md finding "deprecation as prose, not metadata" — Duolingo did not ship an RDF `replacedBy` triple or a redirect API; the rename surfaced only in product release notes and forum threads. Tombstones like this one are how the library represents the migration: enough context for any future agent reading the library to understand "if I encounter 'Lingot' in an old document or third-party reference, it means the modern 'Gems.'"_
