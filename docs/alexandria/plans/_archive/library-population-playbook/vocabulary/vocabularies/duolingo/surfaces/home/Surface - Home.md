# Home

## WHAT: Definition

_Stub — the Path-rendering screen; the primary surface a Learner returns to between Lessons. The Home surface displays the winding Path of lesson nodes, the Learner's current position, upcoming nodes, and contextual nudges (Streak reminder, Daily Quest progress). The Home surface was substantially redesigned in 2022 to replace the Skill Tree grid layout with the current linear Path layout._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Path]] (the Path is the content the Home surface renders), [[Entity - Lesson]] (tapping a node on the Home surface initiates a Lesson), [[Economy-instance - Streak]] (Streak is prominently displayed on Home), [[Pattern - Daily Engagement Loop]] (Home is the primary re-entry surface the Loop returns the Learner to)._
