# Profile

## WHAT: Definition

_Stub — the Learner's own stats surface. Displays XP totals, current Streak count and history, current League placement, earned Achievements, and Course progress summary. Also the surface where Friends can view a Learner's public stats._

## WHERE: Ecosystem

_Stub — links to: [[Role - Learner]] (Profile is the Learner's self-view), [[Economy-instance - Streak]] (Streak history displayed on Profile), [[Economy-instance - XP]] (lifetime and weekly XP displayed on Profile), [[Economy-instance - League]] (current League placement shown on Profile), [[Role - Friend]] (Friends can view each other's Profiles)._
