# XP System

## WHAT: Definition

_Stub — the engine that awards XP for Lesson completion, Story completion, and practice activity; aggregates XP into the weekly total that drives Leaderboard ranking; and contributes to the Learner's daily Goal progress. The XP System is the primary scoring engine underneath the product's competitive and social surfaces._

_Naming-history note: XP is borrowed from RPGs — mechanism-adjacent vocabulary that Duolingo accepts because the player audience already knows it from gaming. The families.md gaming-family analysis explicitly names XP as an example of RPG vocabulary that ports cleanly to gamified-life-OS products: "players meet aesthetics; designers reason mechanics." XP is mechanism-named in the strict sense (it describes an accounting system, not a felt encounter), but unlike `PaymentIntent`, it has a decades-old felt-experience meaning in the target audience. The borrowing is intentional; the audience recognition pre-exists. Per the [[Standard - Duolingo Nomenclature Signature]], this is the acceptable exception: borrowed vocabulary from the player's prior-knowledge set._
