# DuoRadio

## WHAT: Definition

_Stub — episodic listening-practice content delivered as audio episodes, hosted by Duolingo characters. Each episode is a conversational story in the target language, narrated at a measured pace for learners, with key vocabulary explained in-episode. DuoRadio is a mascot-adjacent branded surface — the "Duo" prefix signals the entertainment-surface exception in the [[Standard - Duolingo Nomenclature Signature]]: character and brand names are reserved for surfaces where the named identity IS the delivery mechanism._

_Stub — links to: [[Capability - Listening]] (DuoRadio is a Listening-modality surface), [[Entity - Course]] (DuoRadio episodes are language-pair scoped), [[Entity - Story]] (Stories and DuoRadio are parallel narrative-format content types; Stories are interactive, DuoRadio is audio-passive)._
