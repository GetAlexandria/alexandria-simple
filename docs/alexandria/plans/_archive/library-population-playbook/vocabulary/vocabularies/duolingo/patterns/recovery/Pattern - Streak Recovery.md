# Streak Recovery

## WHAT: Definition

_Stub — the two-mode recovery Pattern for when a Streak is threatened or broken. Mode one: Streak Freeze (preventive) — purchased in the Shop before a missed day, automatically consumed when the Streak Engine records no qualifying activity for the day. Mode two: Streak Repair (post-loss) — purchased after a Streak breaks, restoring the Streak count to its pre-loss value. The Pattern covers both modes because they serve the same user need (Streak preservation) through distinct temporal positions (before vs after the loss event)._

_The Streak Freeze is the canonical example of the "Freeze meta-resource" pattern cited in families.md for gamified-life-OS products. A meta-resource is a resource whose only purpose is to protect another resource — Streak Freeze has no independent utility; it exists only to shield the Streak. Families.md specifically recommends that Hearthfire and similar life-OS products implement this Pattern verbatim: "Borrow Freeze cleanly into gamified-life-OS. A meta-resource that protects another resource is a portable mechanic." The retention evidence — Duolingo has reported retention lifts in the range of 48%+ associated with Streak Freeze adoption — makes this one of the most empirically grounded mechanics in the gamified-life-OS family._
