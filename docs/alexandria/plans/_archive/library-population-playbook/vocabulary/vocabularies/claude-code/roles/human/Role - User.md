# User

## WHAT: Definition

_Stub — the human developer at the CLI or IDE. The User initiates tasks, reviews output, approves or rejects diffs, manages Memory files, and decides when to enter Plan mode or invoke a Skill. In families.md terms, the User is the Operator: the person directing the Agent toward a goal._

_Note on naming: Claude Code's docs use "you" throughout. "User" is the stub label for this Role; the product itself addresses the User in second person. A director building something Claude Code-shaped might choose a more cast-specific name (Developer, Engineer, Director) if the audience is narrower._

## WHERE: Ecosystem

_Stub — links to: [[Role - Agent]] (the counterpart the User directs), [[Surface - CLI]] (the primary surface the User operates on), [[Surface - Plan Mode]] (the mode the User enters to review before acting), [[Entity - Session]] (the durable transcript the User accumulates), [[Entity - Memory]] (the cross-session knowledge the User manages)._
