# Soul Gathering

## WHAT: Definition

_Stub — the capability of filling the Soul meter by striking enemies and certain Soul-infused objects with the Nail. Every Nail hit on a living enemy generates Soul; the amount gathered per hit is a fixed base value, modifiable by Charms. Soul Gathering is the input side of the [[System - Soul Economy]] — the player must engage in combat (taking on risk) to generate the resource that enables healing and spell-casting (the reward). The loop is: fight → gather Soul → spend Soul → fight again._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Soul]] (the resource gathered), [[System - Soul Economy]] (the gather/spend system), [[Capability - Healing]] (a primary Soul sink), [[Capability - Casting Spells]] (a primary Soul sink), [[Entity - Charm]] (Charms like Soul Catcher increase gather rate)._
