# Soul

## WHAT: Definition

_Stub — the combat resource economy; Soul enters the economy via Nail hits on enemies (source), is stored in the Soul meter (capacity expandable via Vessel Fragments), and exits via Focus (healing sink) and Spells (offensive sink). The strategic choice between hoarding Soul for healing vs spending it on Spells is the core combat-resource decision. Soul is a within-encounter economy — it does not persist meaningfully between Benches (resting partially restores Soul); its flow is primarily a per-fight resource-management problem. [[Entity - Soul]] is the object-level card._
