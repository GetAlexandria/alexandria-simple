# Healing

## WHAT: Definition

_Stub — the capability of restoring one Mask of health by holding the Focus input while stationary; the action consumes Soul from the meter. Focus is the verb; Healing is the effect. The mechanic creates deliberate risk: Focusing takes several seconds of stand-still vulnerability during which the Knight takes damage at double effectiveness. The player must create safe windows for Healing, either by clearing an area, retreating, or using Charms that speed the Focus animation. This tension — I have Soul, I need health, can I afford the window — is the core rhythm of Hollow Knight's combat economy._
