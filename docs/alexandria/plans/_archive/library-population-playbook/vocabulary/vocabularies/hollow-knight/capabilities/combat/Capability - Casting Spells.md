# Casting Spells

## WHAT: Definition

_Stub — the capability of casting one of three Spells by spending Soul: Vengeful Spirit (a projectile fired horizontally), Howling Wraiths (an upward burst), and Desolate Dive (a ground-slam). Each Spell has an upgraded version acquired later in the game (Shade Soul, Abyss Shriek, Descending Dark). Spells are the ranged and AoE options in a combat system otherwise dominated by melee Nail strikes; they are the primary use case for accumulated Soul in Boss encounters._

_Stub — links to: [[Entity - Soul]] (the resource consumed by Spells), [[System - Soul Economy]] (Casting Spells is a primary Soul sink), [[Capability - Soul Gathering]] (the input that enables Spell casting), [[Entity - Charm]] (Shaman Stone, Spell Twister modify Spell damage and cost)._
