# Pale Ore

## WHAT: Definition

_Stub — a rare upgrade material used by the Nailsmith to upgrade the Knight's Nail (the primary weapon) through four tiers of increasing power. Pale Ore is scarce — only six exist in the game — and each successive Nail upgrade requires more ore. Finding Pale Ore is a deliberate mid-to-late-game effort; it is awarded by defeating optional Bosses, found in hidden World locations, and purchased from a specific NPC._
