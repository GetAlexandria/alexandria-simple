# Soul Economy

## WHAT: Definition

_Stub — the gather-vs-spend resource flow governing Soul. The Soul Economy has a source (Nail hits on enemies fill the meter), a storage vessel (the Soul meter, expandable via Vessel Fragments), and two primary sinks (Focus for healing, Spells for combat). The flow creates a strategic tension: Soul gathered in combat can be hoarded for healing or spent offensively for Spells, but not both. The Soul Economy is the system; [[Entity - Soul]] is the user-facing noun the Economy tracks. This distinction follows the Duolingo pattern where `user_visible: false` applies to the system underlying a user-visible entity._
