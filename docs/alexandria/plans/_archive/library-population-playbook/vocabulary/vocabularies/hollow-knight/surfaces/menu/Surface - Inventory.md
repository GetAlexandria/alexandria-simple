# Inventory

## WHAT: Definition

_Stub — the equipment, items, and key-items screen; opened from the pause menu. The Inventory shows the Knight's currently held key items (Quill, Simple Key, Tram Pass, etc.), quest items, and the Notches panel indicating current Notch usage. The Inventory is the player's reference for what they are carrying; it is not the Charm loadout screen (which is a separate surface) but the broader items-in-possession view._
