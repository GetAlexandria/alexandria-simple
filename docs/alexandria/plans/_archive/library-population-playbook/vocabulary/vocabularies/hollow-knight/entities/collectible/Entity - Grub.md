# Grub

## WHAT: Definition

_Stub — a collectible found throughout the World, trapped in glass jars; breaking the jar rescues the Grub. There are 46 Grubs hidden across Hallownest. Rescuing Grubs earns rewards from the Grubfather NPC (who tracks rescued Grub count) including Geo, Mask Shards, and Rancid Eggs. The Grub functions as Hollow Knight's primary exploration-reward collectible — finding all 46 is a completionist goal, and each one is individually placed to reward thorough area exploration._
