# Stag Fast Travel

## WHAT: Definition

_Stub — the fast-travel system: a network of Stag Stations connected by underground stagways, serviced by the Old Stag (a named giant beetle character). The player unlocks individual Stag Stations by ringing a bell at each station; once unlocked, any station can be traveled to from any other unlocked station by summoning the Old Stag. The system is named from its aesthetic: travel is by beetle-drawn carriage through underground tunnels; "Stag" is the carrier; "Station" is the node. The result is a fast-travel vocabulary that feels like it belongs to the world's mythology rather than to the game's UI layer._
