# Vessel Fragment

## WHAT: Definition

_Stub — a fractional Soul-capacity upgrade. Collecting three Vessel Fragments permanently increases the Knight's maximum Soul storage by one notch on the Soul meter (displayed as an expanded vessel icon). The "Vessel" name anchors the game's core mythology — the Knight is a Vessel, an empty shell designed to contain something; the Vessel Fragments are literal pieces of that container, found scattered across Hallownest. Collecting them makes the Vessel more whole._
