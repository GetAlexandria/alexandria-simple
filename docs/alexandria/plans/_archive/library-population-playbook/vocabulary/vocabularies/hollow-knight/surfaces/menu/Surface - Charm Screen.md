# Charm Screen

## WHAT: Definition

_Stub — the Charm loadout configuration surface; the screen where the player equips and unequips Charms from the Knight's collection. Charms can only be swapped here while the Knight is at a Bench — attempting to modify the loadout outside a Bench is not possible. The Charm Screen displays all owned Charms, the Notch cost of each, and the current total Notch usage vs available Notches._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Charm]] (the items configured here), [[System - Charm Notch System]] (the Notch economy governing what can be equipped), [[System - Bench Save]] (Bench interaction is required to access Charm configuration), [[Economy-instance - Charm Notch]] (the slot resource displayed and consumed here)._
