# Greenpath

## WHAT: Definition

_Stub — the second major area; a lush, overgrown biome dominated by vegetation, acid pools, and moss-covered passages. Greenpath is where the player obtains the Mothwing Cloak (granting the Dashing capability) — the first major mobility upgrade and the first instance of the [[Pattern - Retroactive Unlock]] pattern. The name is a compound place-name per the [[Standard - Hollow Knight Nomenclature Signature]]: green (biome color, life, overgrowth) + path (a way through, a traversal route). It also introduces Hornet as a recurring NPC/adversary and contains the Unn lore path._
