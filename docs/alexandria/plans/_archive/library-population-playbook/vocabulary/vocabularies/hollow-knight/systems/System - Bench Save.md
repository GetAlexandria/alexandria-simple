# Bench Save

## WHAT: Definition

_Stub — the save-and-rest discipline: sitting at a Bench saves the game, fully restores the Knight's Masks, restores Soul to a partial base level, triggers Map Updating (if the Quill is held), and resets all enemies in the game world. The Bench is the game's only save mechanism — the Knight cannot save at will. Every Bench is a permanent fixture in the World with a visible location; finding Benches is a navigation milestone. The Bench is named from the folk-fantasy register of the [[Standard - Hollow Knight Nomenclature Signature]]: a bench is something you sit on to rest, not a "save point" or "checkpoint node."_

_This is the canonical families.md "state-capture-with-cost" (Soulslike Bonfire) pattern in Hollow Knight's form. The Bench bundles: checkpoint (progress saved), rest (health restored), risk-reset (all enemies respawn). The cost of using a Bench is not explicit — resting is free — but the reset of all enemies is a strategic consequence: enemies the player had already cleared come back, restoring the World to its prior hostility. The Bench is therefore not an unconditional save; it is a save that resets the stakes. This is the aesthetic-naming version of a mechanic that Dark Souls names "Bonfire" and that other games name "Rest Point." All three inhabit the same pattern; each name inhabits a different aesthetic register._
