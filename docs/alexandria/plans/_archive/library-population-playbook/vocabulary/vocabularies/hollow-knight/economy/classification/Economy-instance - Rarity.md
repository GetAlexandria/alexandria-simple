# Rarity

## WHAT: Definition

_Stub — the implicit scarcity economy governing Charm (and item) acquisition; some Charms are straightforwardly available from merchants for Geo (common, accessible), while others are uniquely placed — behind Boss defeats, hidden in obscure World locations, or requiring specific quest completions (rare, earned). Hollow Knight does not expose an explicit Rarity tier system with named tiers (no "Common/Rare/Epic/Legendary" labels); Rarity is structural rather than labeled. The economy effect is real nonetheless: the player experiences some Charms as routine purchases and others as discoveries or rewards. "Rarity" is the Vocabulary-module-level noun for this implicit gradient; it is not a player-facing noun in the game itself, hence `user_visible: false`._
