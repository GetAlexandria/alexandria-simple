# Soul

## WHAT: Definition

_Stub — the combat resource gathered by striking enemies with the Nail and spent on Healing (Focus) and Spells (Vengeful Spirit, Howling Wraiths, Desolate Dive). The Soul meter fills as the Knight attacks and depletes as the Knight casts or focuses. Maximum Soul capacity starts at a base value and expands via Vessel Fragments._
