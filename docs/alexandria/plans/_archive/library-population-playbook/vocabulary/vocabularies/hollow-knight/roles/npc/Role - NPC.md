# NPC

## WHAT: Definition

_Stub — a non-hostile character encountered in the World; each is a named individual, never a category. The canonical NPCs are: Quirrel (traveling scholar), Cornifer (cartographer), Iselda (map and quill merchant), Sly (general merchant), Salubra (charm-notch merchant), Zote (self-aggrandizing knight), Hornet (recurring figure, also a Boss), and the Seer (dream-lore guide). "NPC" is an engine-side category label that never appears in the game itself — each character is known only by their name, per the [[Standard - Hollow Knight Nomenclature Signature]]'s rule that NPCs are characters with names, not categories._
