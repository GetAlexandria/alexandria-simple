# Map

## WHAT: Definition

_Stub — the in-game cartographic record of the World. The Map is purchased from Cornifer (the cartographer NPC) area by area; an area's map starts blank until purchased, and the purchased map remains incomplete (showing only Cornifer's hand-drawn sketch) until the Knight sits at a Bench with a Quill in inventory, at which point the map auto-updates to reflect visited rooms. The Map is the primary navigational reference for a large, non-linear World._
