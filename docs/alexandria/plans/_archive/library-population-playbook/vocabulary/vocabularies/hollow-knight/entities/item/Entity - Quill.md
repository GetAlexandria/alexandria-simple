# Quill

## WHAT: Definition

_Stub — a one-time-purchase item sold by Iselda that enables the Map to update automatically whenever the Knight rests at a Bench. Without the Quill, Map sketches never fill in with visited rooms regardless of how much the player explores. The Quill is a permanent unlock; once bought, all future Bench rests trigger Map updates for any purchased area map. The name inhabits the cartographer aesthetic: Cornifer draws Maps by hand with a quill, and the player equips a quill to participate in that record-keeping._
