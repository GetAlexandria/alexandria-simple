# Cleaning Fee

## WHAT: Definition

_Stub — a one-time flat fee charged to the [[Role - Guest]] per [[Entity - Reservation]] to cover post-stay cleaning costs. The Cleaning Fee is set by the [[Role - Host]] in the [[Surface - Listing Editor]] and is added to the Guest's total payment alongside the [[Economy-instance - Nightly Rate]] and [[Economy-instance - Service Fee]]. The Cleaning Fee is disclosed in the price breakdown on [[Surface - Listing Detail Page]] and [[Surface - Booking Flow]]. Refundability of the Cleaning Fee under cancellation depends on the [[Pattern - Cancellation]] policy tier._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Nightly Rate]] (the per-night component this fee is added to), [[Economy-instance - Service Fee]] (the platform fee this charge appears alongside), [[Entity - Payment]] (the Payment that includes this fee), [[Capability - Pricing]] (the Host capability that sets this fee)._
