# Pricing

## WHAT: Definition

_Stub — the [[Role - Host]]'s revenue management action: setting and adjusting the [[Economy-instance - Nightly Rate]], [[Economy-instance - Cleaning Fee]], and [[Economy-instance - Security Deposit]] on a [[Entity - Listing]], and optionally enabling [[System - Smart Pricing]] for dynamic rate adjustment. Pricing is managed primarily in the [[Surface - Calendar]] (per-date and per-range overrides) and in the [[Surface - Listing Editor]] (base rate defaults). Pricing is the primary lever for Host revenue optimization._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Calendar]] (per-date pricing managed here), [[Surface - Listing Editor]] (base rate and fee defaults set here), [[Economy-instance - Nightly Rate]] (the rate this Capability manages), [[Economy-instance - Cleaning Fee]] (the fee this Capability manages), [[System - Smart Pricing]] (the automated system that can drive this Capability)._
