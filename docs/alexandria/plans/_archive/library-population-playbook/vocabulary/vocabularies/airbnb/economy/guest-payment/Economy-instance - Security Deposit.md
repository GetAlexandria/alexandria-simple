# Security Deposit

## WHAT: Definition

_Stub — an optional hold or charge set by the [[Role - Host]] on a [[Entity - Listing]] to cover potential damages beyond normal wear, separate from [[System - AirCover]] Host protection. Guests are informed of the Security Deposit amount before booking. Historically Airbnb held a payment authorization; the Security Deposit mechanism has evolved as AirCover's host damage protection expanded — Airbnb now encourages Hosts to use AirCover rather than a Security Deposit for most damage scenarios. The Security Deposit is an older economy-layer instrument that coexists with the newer AirCover regime._

## WHERE: Ecosystem

_Stub — links to: [[System - AirCover]] (the newer, preferred mechanism for Host damage protection that partially supersedes Security Deposit), [[Entity - Resolution]] (the Resolution process through which Security Deposit claims are adjudicated), [[Entity - Listing]] (Security Deposit is declared at the Listing level), [[Entity - Payment]] (Security Deposit hold or charge is part of the payment authorization)._
