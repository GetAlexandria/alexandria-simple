# Listing Creation

## WHAT: Definition

_Stub — the [[Role - Host]]'s foundational onboarding action: the multi-step flow through which a Host publishes a new [[Entity - Listing]]. Listing Creation collects property type, location, sleeping arrangement details, [[Entity - Amenity|Amenities]], [[Entity - Photo|Photos]], title, description, house rules, cancellation policy, and pricing defaults. At completion, the Listing is submitted for review and, if approved, made active on the [[Surface - Search]] surface._

_Stub — links to: [[Entity - Listing]] (the artifact Listing Creation produces), [[Surface - Listing Editor]] (the surface used for ongoing management after initial creation), [[Entity - Photo]] (Photos captured during Listing Creation), [[Entity - Amenity]] (Amenities declared during Listing Creation), [[Economy-instance - Nightly Rate]] (the base rate set during Listing Creation)._
