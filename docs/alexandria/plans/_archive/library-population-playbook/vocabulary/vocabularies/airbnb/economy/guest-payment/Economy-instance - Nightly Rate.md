# Nightly Rate

## WHAT: Definition

_Stub — the per-night price a [[Role - Guest]] pays for a [[Entity - Listing]]: the core pricing unit in Airbnb's guest-payment stack. The Nightly Rate is set by the [[Role - Host]] in the [[Surface - Listing Editor]] as a base rate, customizable per date or date range in the [[Surface - Calendar]], and optionally adjusted dynamically by [[System - Smart Pricing]]. Guests see the Nightly Rate prominently in [[Surface - Search]] result cards and in the price breakdown on [[Surface - Listing Detail Page]] and in the [[Surface - Booking Flow]]._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Cleaning Fee]] (added to Nightly Rate in the Guest's price total), [[Economy-instance - Service Fee]] (Airbnb's platform fee on top of the nightly subtotal), [[Capability - Pricing]] (the Host capability that sets this rate), [[System - Smart Pricing]] (the system that can automatically adjust this rate), [[Surface - Calendar]] (where per-date overrides are managed)._
