# Smart Pricing

## WHAT: Definition

_Stub — the [[Role - Host]]-facing dynamic pricing tool: the opt-in feature through which a Host enables the [[System - Smart Pricing]] engine to automatically adjust their [[Economy-instance - Nightly Rate]] within Host-configured floor and ceiling bounds. As an Economy-instance, Smart Pricing is the named feature product that surfaces in the [[Surface - Calendar]] and [[Surface - Listing Editor]] — distinct from the [[System - Smart Pricing]] card, which describes the engine-internal mechanism. Smart Pricing is user-visible (Hosts see it by name, can enable/disable it, and set bounds); the pricing engine behind it is not._

## WHERE: Ecosystem

_Stub — links to: [[System - Smart Pricing]] (the engine this Economy-instance exposes to Hosts), [[Economy-instance - Nightly Rate]] (the rate this tool modifies), [[Surface - Calendar]] (where Smart Pricing is managed and visualized per date), [[Surface - Listing Editor]] (where Smart Pricing is enabled and bounds are set), [[Capability - Pricing]] (the Host Capability this tool assists)._
