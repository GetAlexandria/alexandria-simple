# Listing Editor

## WHAT: Definition

_Stub — the [[Role - Host]]'s content management surface for a [[Entity - Listing]]: where the Host edits title, description, [[Entity - Photo|Photos]], [[Entity - Amenity|Amenities]], house rules, pricing defaults, cancellation policy, and check-in/checkout instructions. The Listing Editor is the mechanism-named counterpart to the Guest's experience of the [[Surface - Listing Detail Page]] — what the Host edits here becomes what the Guest sees there. Airbnb uses descriptive utility naming for Host tools (Listing Editor, Calendar, Earnings) rather than the felt-experience naming used for Guest surfaces._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Listing]] (the Listing this Editor manages), [[Entity - Photo]] (Photo upload and ordering), [[Entity - Amenity]] (Amenity declarations), [[Surface - Listing Detail Page]] (the Guest-facing output of what the Host edits here), [[Surface - Calendar]] (availability managed separately in the Calendar), [[Capability - Listing Creation]] (the initial flow that creates the Listing before this Editor takes over ongoing management)._

## WHY: Rationale

_Stub — owner-supplied._

## WHEN: Timeline

_Stub._

## HOW: Specification

_Stub — to be enriched with: Listing Editor section structure (title, property type, rooms and spaces, location, amenities, photos, title and description, pricing, availability, rules, policies); which edits take effect immediately vs. require re-review; how edits affect existing Reservations; how Listing Editor access is scoped for [[Role - Co-Host|Co-Hosts]]._
