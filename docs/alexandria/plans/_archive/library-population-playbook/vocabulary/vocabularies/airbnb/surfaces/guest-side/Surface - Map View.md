# Map View

## WHAT: Definition

_Stub — the geographic display mode for [[Surface - Search]] results: a split-pane or full-screen map that plots available [[Entity - Listing|Listings]] as price pins against a geographic tile. Map View is toggled from within Search and maintains the active filter state. It allows a [[Role - Guest]] to reason about location relative to points of interest and to understand price geography within a destination. A selected pin expands to show the Listing card._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Search]] (the parent surface Map View is a mode of), [[Entity - Listing]] (the supply units plotted as pins), [[Capability - Searching]] (the Capability producing the plotted results), [[Capability - Filtering]] (filters applied in Search carry over to Map View)._
