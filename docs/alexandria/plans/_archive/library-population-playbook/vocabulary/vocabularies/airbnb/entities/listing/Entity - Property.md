# Property

## WHAT: Definition

_Stub — the physical or real-world thing that a [[Entity - Listing]] represents. The Property is the location, structure, and space — the house, apartment, cabin, or room that a [[Role - Guest]] will physically occupy during a [[Entity - Stay]]. The Property persists even when the Listing is deactivated; the Listing is the commerce artifact on top of the Property. Airbnb uses "Property" primarily in Host-facing help documentation and internal tools; Guests more often encounter the Listing or the address._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Listing]] (the published, bookable representation of this Property), [[Entity - Room]] (a sub-unit of a Property when the Host rents individual rooms), [[Entity - Amenity]] (the features that belong to this Property and are declared on the Listing), [[Entity - Photo]] (visual documentation of the Property attached to the Listing)._
