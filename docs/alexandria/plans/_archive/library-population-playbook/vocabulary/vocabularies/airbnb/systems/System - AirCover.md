# AirCover

## WHAT: Definition

_Stub — Airbnb's insurance and protection product: the system-layer and user-facing brand that delivers both Host damage protection and Guest stay guarantees. AirCover for Hosts covers damage to property caused by Guests (up to the declared coverage amount) and host liability protection. AirCover for Guests provides a rebooking guarantee and refund eligibility if a listing is significantly misrepresented or unavailable on arrival. AirCover is the one system in the Airbnb vocabulary that is explicitly user-facing as a named product — it earns the brand name because it is a sold feature with user-visible value._

_As a faceted concept, AirCover operates simultaneously as a System (the automated and human-adjudicated process for handling damage and stay-quality claims) and as an Economy-layer product (a named benefit that has real market value and is used in conversion marketing). Airbnb chose "AirCover" as a compound brand name — the "Air" prefix marking it as Airbnb-owned, the "Cover" word evoking insurance and protection. This is the deliberate exception to the plain-English rule in the signature: a branded exception because it is a product, not just a feature._
