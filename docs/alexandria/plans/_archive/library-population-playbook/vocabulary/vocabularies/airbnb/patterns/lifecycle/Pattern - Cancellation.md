# Cancellation

## WHAT: Definition

_Stub — the named-tier pattern that governs [[Entity - Refund]] amounts when a [[Entity - Reservation]] is cancelled. Cancellation policies are attached to a [[Entity - Listing]] at booking time and come in named tiers: Flexible (full refund if cancelled at least 24 hours before check-in), Moderate (full refund if cancelled 5 days before check-in), Strict (50% refund if cancelled at least 7 days before), and Non-Refundable (discounted rate, no refund). The tier names are user-facing — Guests see the cancellation policy explicitly before completing the [[Capability - Booking]] flow._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Reservation]] (the Reservation a Cancellation applies to), [[Entity - Refund]] (the financial outcome governed by this Pattern), [[Capability - Cancelling]] (the Capability that triggers this Pattern's rules), [[Surface - Listing Detail Page]] (where the cancellation policy is disclosed to Guests before booking)._
