# Searching

## WHAT: Definition

_Stub — the [[Role - Guest]]'s foundational discovery action: entering a destination, dates, and guest count to retrieve a ranked set of available [[Entity - Listing|Listings]]. Searching is the entry point to the [[Surface - Search]] surface and the action that activates the [[System - Search Ranking]] engine. Searching produces a result set that the Guest then narrows with [[Capability - Filtering]]._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Search]] (the surface this Capability operates on), [[System - Search Ranking]] (the system that determines result order), [[Capability - Filtering]] (the follow-on Capability that narrows results), [[Entity - Listing]] (the objects returned by a search)._

## WHY: Rationale

_Stub — owner-supplied._

_Stub._
