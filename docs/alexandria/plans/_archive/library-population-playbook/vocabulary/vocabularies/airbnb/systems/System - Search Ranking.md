# Search Ranking

## WHAT: Definition

_Stub — the engine-internal system that determines the order in which [[Entity - Listing|Listings]] appear in [[Surface - Search]] results for a given Guest query. Search Ranking ingests Listing quality signals (photo count, review volume and score, response rate, acceptance rate, [[Role - Superhost]] status, Listing completeness), availability, price competitiveness, and Guest personalization signals to produce a ranked result set. Search Ranking is engine-internal — Hosts experience its effects (more or fewer bookings) but do not directly interact with it as a named product surface._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Search]] (the surface where ranking effects are visible to Guests), [[Entity - Listing]] (the objects being ranked), [[Economy-instance - Star Rating]] (a ranking signal), [[Role - Superhost]] (a ranking signal), [[System - Smart Pricing]] (price competitiveness is a ranking input)._
