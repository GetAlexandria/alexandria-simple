# Stays

## WHAT: Definition

_Stub — Airbnb's core product domain: the homes-and-rentals marketplace that constitutes the majority of the platform's supply, demand, and revenue. The Stays domain includes all of the primary [[Entity - Listing]] types (Entire Place, Private Room, Shared Room), all of the core [[Role - Host]] and [[Role - Guest]] flows, and all of the lifecycle mechanics described in [[Pattern - Two-Sided Lifecycle]]. "Stays" is Airbnb's own domain label — appearing in navigation as a product line alongside [[Domain - Experiences]]._
