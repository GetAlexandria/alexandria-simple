# Host Dashboard

## WHAT: Definition

_Stub — the [[Role - Host]]'s primary management surface: the operational hub where Hosts manage [[Entity - Reservation|Reservations]], monitor [[Entity - Message|Messages]], track [[Economy-instance - Payout|Payouts]], and access [[Surface - Calendar]], [[Surface - Listing Editor]], and [[Surface - Earnings]]. Airbnb calls this surface "Today" in its app navigation — the Host's daily work view. The Host Dashboard surfaces the most time-sensitive items: pending booking requests, arriving Guests, and unread messages._

## WHERE: Ecosystem

_Stub — links to: [[Role - Host]] (the primary user of this surface), [[Entity - Reservation]] (Reservations managed here), [[Surface - Calendar]] (linked from the Dashboard), [[Surface - Listing Editor]] (linked from the Dashboard), [[Surface - Earnings]] (linked from the Dashboard), [[Entity - Message]] (Messages accessible from the Dashboard inbox)._
