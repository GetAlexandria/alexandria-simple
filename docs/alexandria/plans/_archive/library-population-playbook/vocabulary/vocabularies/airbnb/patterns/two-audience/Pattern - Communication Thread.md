# Communication Thread

## WHAT: Definition

_Stub — the per-booking instance of the two-audience split applied to communication: a [[Entity - Thread]] shared between one [[Role - Guest]] and one [[Role - Host]] (or [[Role - Co-Host]]) that presents differently to each party but shares the same message history. The Guest sees it as part of their Trip; the Host sees it in their Inbox alongside all other Guest threads. Each party can initiate; both see the same messages; neither can delete what the other wrote. [[Role - Customer Support]] has read access for dispute adjudication._
