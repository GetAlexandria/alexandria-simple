# Host

## WHAT: Definition

_Stub — the supply-side principal: the person or entity who publishes an [[Entity - Listing]], accepts [[Entity - Reservation|Reservations]], and receives [[Economy-instance - Payout|Payouts]]. Host is the primary user of all host-side surfaces ([[Surface - Host Dashboard]], [[Surface - Calendar]], [[Surface - Listing Editor]], [[Surface - Earnings]]). Airbnb commits to "Host" throughout its UI — never "Landlord," "Owner," or "Supplier."_

## WHERE: Ecosystem

_Stub — links to: [[Entity - Listing]] (the Host's published supply unit), [[Surface - Host Dashboard]] (the Host's primary management surface), [[Capability - Listing Creation]] (the Host's foundational action), [[Capability - Accepting]] (the Host's booking-response action), [[Role - Superhost]] (the earned-tier variant of this role), [[Role - Co-Host]] (the delegated-management variant)._

## WHY: Rationale

_Stub — owner-supplied._

_Stub._

## HOW: Specification

_Stub — to be enriched with: Host account creation and identity verification; Host payout setup (bank account, PayPal, Payoneer); Host obligations (house rules, check-in instructions, cancellation policy); Host response rate requirements; the relationship between Host identity and the Listing identity (one Host can have multiple Listings)._
