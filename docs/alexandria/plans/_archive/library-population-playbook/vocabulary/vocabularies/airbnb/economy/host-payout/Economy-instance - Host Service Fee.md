# Host Service Fee

## WHAT: Definition

_Stub — Airbnb's platform charge deducted from the [[Role - Host]]'s [[Economy-instance - Payout]]: a percentage of the booking subtotal that Airbnb retains as its revenue on the Host side. The Host Service Fee is visible to Hosts in the [[Surface - Earnings]] breakdown per [[Entity - Reservation]]. It is the Host-side counterpart to the [[Economy-instance - Service Fee]] on the Guest side — together, Host and Guest Service Fees are Airbnb's two-sided revenue mechanism. Airbnb offers Hosts a choice between a split-fee model (both Host and Guest pay a Service Fee) and a Host-only fee model (Host pays a higher fee, Guest pays no visible fee)._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Payout]] (the Payout this fee is deducted from), [[Economy-instance - Service Fee]] (the Guest-side counterpart), [[Surface - Earnings]] (where Hosts see this deduction per Reservation)._
