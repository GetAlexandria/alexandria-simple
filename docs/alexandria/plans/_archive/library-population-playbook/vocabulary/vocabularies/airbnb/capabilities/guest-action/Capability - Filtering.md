# Filtering

## WHAT: Definition

_Stub — the [[Role - Guest]]'s refinement action: narrowing [[Capability - Searching]] results by applying constraints on price range, [[Entity - Amenity|Amenities]], property type, instant-book eligibility, [[Role - Superhost]] status, and other attributes. Filtering executes within the [[Surface - Search]] and [[Surface - Map View]] surfaces. [[Entity - Amenity]] is the most-used filter dimension; price range is the second._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Search]] (the primary surface where Filtering is applied), [[Surface - Map View]] (filters carry over to Map View), [[Entity - Amenity]] (the primary filter dimension), [[Capability - Searching]] (the upstream Capability whose results Filtering refines)._

## WHY: Rationale

_Stub — owner-supplied._

## WHEN: Timeline

_Stub._

## HOW: Specification

_Stub — to be enriched with: filter dimensions and their UI controls (price range slider, amenity checkboxes, property type tiles, instant book toggle, Superhost toggle, accessibility features filter, room/bed count, pet-friendly); how filters persist across map pan; filter count badge; how applied filters affect [[System - Search Ranking]] (filtering doesn't change rank order of qualifying results, but changes the pool)._
