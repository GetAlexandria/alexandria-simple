# Room

## WHAT: Definition

_Stub — a sub-unit of a [[Entity - Property]]: a discrete rentable space within a larger property structure. Room appears in the Listing type taxonomy — a Host can list an Entire Place, a Private Room (Guest gets a room; Host or others may share common areas), or a Shared Room (Guest shares the sleeping space). "Room" in Airbnb's vocabulary names both the structural unit and the listing-type category._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Property]] (the enclosing Property this Room is part of), [[Entity - Listing]] (the Listing that publishes this Room as the bookable unit), [[Entity - Amenity]] (Amenities declared at the Room level vs Property level)._
