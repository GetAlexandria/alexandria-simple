# Message

## WHAT: Definition

_Stub — a single communication sent within a [[Entity - Thread]] between a [[Role - Guest]] and a [[Role - Host]] (or [[Role - Co-Host]]). Messages are the atomic unit of Airbnb's in-platform communication system. All pre-booking and post-booking communication between Guests and Hosts is expected to happen through Airbnb Messages rather than external channels — this keeps the communication record visible to [[Role - Customer Support]] for dispute purposes._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Thread]] (the conversation container this Message belongs to), [[Entity - Inquiry]] (a pre-booking Message of a specific type), [[Capability - Messaging]] (the Capability that produces Messages), [[Role - Guest]] (a Message sender or recipient), [[Role - Host]] (a Message sender or recipient)._
