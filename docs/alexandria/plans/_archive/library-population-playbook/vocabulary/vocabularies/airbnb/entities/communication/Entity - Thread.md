# Thread

## WHAT: Definition

_Stub — the conversation container: the persistent record of all [[Entity - Message|Messages]] between a specific [[Role - Guest]] and [[Role - Host]] pair, typically scoped to a specific [[Entity - Listing]] or [[Entity - Reservation]]. A Thread persists across the lifecycle — it starts with an [[Entity - Inquiry]] or booking request, continues through check-in instructions and stay communications, and remains accessible post-departure. Threads are the communication surface for the [[Pattern - Communication Thread]] pattern._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Message]] (Messages that make up this Thread), [[Entity - Inquiry]] (the type of Message that opens a pre-booking Thread), [[Role - Guest]] (one of the two Thread participants), [[Role - Host]] (the other Thread participant), [[Entity - Reservation]] (the Reservation a Thread is associated with), [[Pattern - Communication Thread]] (the two-audience pattern this Thread embodies)._
