# Earnings

## WHAT: Definition

_Stub — the [[Role - Host]]'s financial reporting surface: the view where Hosts see completed [[Economy-instance - Payout|Payouts]], upcoming payouts, and transaction history by [[Entity - Reservation]]. Airbnb uses "Earnings" rather than "Revenue" or "Income" — the earned-money register that fits the hospitality-register identity of the Host role. The Earnings surface also surfaces [[Economy-instance - Host Service Fee]] deductions per payout and links to tax forms for applicable jurisdictions._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Payout]] (the Payout records displayed here), [[Economy-instance - Host Service Fee]] (deductions visible in the Earnings breakdown), [[Entity - Reservation]] (each Payout is tied to a completed Reservation), [[Role - Host]] (the primary user of this surface)._

_Stub — owner-supplied._

## HOW: Specification

_Stub — to be enriched with: Earnings view modes (calendar view, transaction history, upcoming payouts); payout timing display; how tax withholding and 1099-K forms are accessed; multi-currency Earnings display for Hosts in different countries; how partial cancellations and Refunds appear in the Earnings ledger._
