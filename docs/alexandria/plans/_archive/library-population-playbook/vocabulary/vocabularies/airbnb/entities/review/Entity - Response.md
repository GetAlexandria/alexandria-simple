# Response

## WHAT: Definition

_Stub — a [[Role - Host]]'s optional public reply to a [[Role - Guest]]'s [[Entity - Review]]. A Response is posted beneath the Guest's Review on the Listing page and is visible to all future Guests. Unlike the Review itself (double-blind, time-limited), a Response can be written at any time after the Review is published. Response is Host-only: Guests cannot reply to Host reviews of them. Airbnb names this explicitly "Response" in its help documentation to distinguish it from the [[Capability - Messaging]] system and from review submissions._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Review]] (the Review this Response is attached to), [[Role - Host]] (the principal who writes a Response), [[Surface - Listing Detail Page]] (where Reviews and their Responses are displayed publicly)._
