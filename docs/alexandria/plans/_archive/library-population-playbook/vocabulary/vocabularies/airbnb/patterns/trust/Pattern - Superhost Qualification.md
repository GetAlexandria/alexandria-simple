# Superhost Qualification

## WHAT: Definition

_Stub — the rules-based pattern by which a [[Role - Host]] earns and retains [[Role - Superhost]] status: meeting all four performance thresholds (minimum stay completions, minimum overall rating, minimum response rate, maximum Host cancellation rate) over a trailing 12-month assessment window. Assessment runs quarterly; Hosts who meet all thresholds are promoted to or retain Superhost; Hosts who fall below any threshold lose it. The quarterly cadence means Superhost status can be gained or lost four times per year._

## WHERE: Ecosystem

_Stub — links to: [[Role - Superhost]] (the Role tier this Pattern governs), [[Economy-instance - Superhost Status]] (the Economy-layer resource earned by this Pattern), [[Entity - Rating]] (the overall rating threshold input), [[Entity - Review]] (review volume contributes to the completed-stays threshold), [[System - Trust and Safety]] (the system that tracks Host performance metrics)._
