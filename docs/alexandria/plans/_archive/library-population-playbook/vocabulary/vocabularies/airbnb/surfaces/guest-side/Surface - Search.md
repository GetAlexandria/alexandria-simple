# Search

## WHAT: Definition

_Stub — the [[Role - Guest]]'s primary discovery surface: the destination-and-date entry point that returns a filtered, ranked grid of [[Entity - Listing|Listings]]. Search is where the Guest's journey begins — entering a destination, travel dates, and guest count — and where [[Capability - Searching]] and [[Capability - Filtering]] execute. The [[System - Search Ranking]] engine determines the order of results. The Search surface includes both a list/grid view and the [[Surface - Map View]] toggle._

## WHERE: Ecosystem

_Stub — links to: [[Capability - Searching]] (the Capability exercised here), [[Capability - Filtering]] (the Capability that narrows Search results), [[System - Search Ranking]] (the system that orders results), [[Surface - Map View]] (the geographic view toggle), [[Surface - Listing Detail Page]] (the destination when a Guest selects a result), [[Entity - Amenity]] (a primary filter dimension)._
