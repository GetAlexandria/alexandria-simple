# Trips Dashboard

## WHAT: Definition

_Stub — the [[Role - Guest]]'s post-booking command surface: the view where all confirmed, active, and past [[Entity - Trip|Trips]] are managed. The Trips Dashboard presents [[Entity - Reservation|Reservations]] to the Guest under the Trip framing — each Trip card shows the property photo, dates, Host name, and quick-access links to check-in details, receipt, and messaging. Upcoming Trips show check-in countdown; active Trips show house rules and emergency contacts; past Trips link to [[Capability - Reviewing]]._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Trip]] (the data objects displayed as cards here), [[Entity - Reservation]] (the transaction-layer record behind each Trip card), [[Capability - Cancelling]] (accessible from a Trip card for upcoming Trips), [[Capability - Reviewing]] (accessible from a past Trip card), [[Surface - Booking Flow]] (where new Trips are created)._

## WHY: Rationale

_Stub — owner-supplied._

_Stub._

## HOW: Specification

_Stub — to be enriched with: Trip status tabs (Upcoming, Currently Staying, Past, Cancelled); Trip card anatomy; deep links from Trip card to messages, receipts, and check-in instructions; how Trips from different booking channels appear; how the Trips Dashboard handles Trip modifications._
