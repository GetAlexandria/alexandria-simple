# Owner

## WHAT: Definition

_Stub — the user who created a [[Entity - Team]] or holds billing responsibility for it. The Owner can delete the team, transfer ownership, and is the primary billing contact. An Owner implicitly has all Admin rights._

## WHERE: Ecosystem

_Stub — links to: [[Role - Admin]] (Admins share management rights; Owner holds billing and deletion rights above them), [[Entity - Team]] (the entity this role owns), [[Economy-instance - Plan]] (the Owner is responsible for the plan and its billing), [[Economy-instance - Editor Seat]] (the Owner provisions and pays for seats)._
