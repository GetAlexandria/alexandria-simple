# Library Publishing

## WHAT: Definition

_Stub — the design-system governance pattern in which a team maintains a designated [[Entity - Library]] File, authors [[Entity - Component]]s and [[Entity - Style]]s there, and publishes updates so that consuming Files automatically receive them. Library Publishing establishes a source-of-truth for design primitives across a [[Entity - Team]] or organization._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Library]] (the entity this pattern manages), [[Capability - Publishing]] (the capability this pattern invokes), [[Entity - Component]] (the primary artifact being distributed), [[Pattern - Component Override]] (Instances in consuming Files use overrides to customize published Components locally)._

## WHY: Rationale

_Stub — owner-supplied._

## WHEN: Timeline

_Stub._

## HOW: Specification

_Stub — to be enriched with: a recommended Library File structure (dedicated Frames per component category), the review-before-publish governance convention, subscriber management, Library versioning conventions (since Figma doesn't have semantic versioning for Libraries natively), and migration patterns for breaking changes._
