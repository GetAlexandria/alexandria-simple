# Style

## WHAT: Definition

_Stub — a named, reusable set of property values that can be applied to [[Entity - Layer]]s. Styles come in four types: Color Styles (solid fills, gradients), Text Styles (font, size, line-height bundles), Effect Styles (shadows, blurs), and Grid Styles (layout grid configurations). Publishing a [[Entity - Library]] shares its Styles across Files, enabling consistent brand tokens before [[Entity - Variable]]s existed (and still alongside them)._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Library]] (Libraries publish Styles for cross-File reuse), [[Entity - Variable]] (Variables are the newer token-level mechanism that partially supersedes Styles for color and spacing), [[Surface - Properties Panel]] (where Styles are applied to Layers), [[Surface - Assets Panel]] (where Styles are browsed)._
