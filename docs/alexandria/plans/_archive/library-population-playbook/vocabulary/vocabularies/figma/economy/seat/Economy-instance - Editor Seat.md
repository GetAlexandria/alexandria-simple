# Editor Seat

## WHAT: Definition

_Stub — the full-access paid seat that grants the ability to create and edit [[Entity - File]]s. Editor Seats are the primary billable unit in Figma's pricing model. A user occupying an Editor Seat can author [[Entity - Component]]s, apply [[Capability - Auto Layout]], publish [[Entity - Library|Libraries]], and use all editing capabilities._

_Figma's seat-tier distinction is a key economic cut: Editor Seats can create; [[Economy-instance - Viewer Seat]]s can view and comment. This binary partition does significant work in the pricing model — it lets organizations add unlimited stakeholder reviewers at low or no cost while billing only for the designers and developers who actively create. The seat is named for what it can do (edit), not for the role that holds it — consistent with [[Standard - Figma Nomenclature Signature]] rule 5._
