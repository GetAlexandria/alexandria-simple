# Admin

## WHAT: Definition

_Stub — a user with administrative rights over a [[Entity - Team]] or organization. Admins manage membership, permissions, and team-level settings. Distinct from [[Role - Owner]], who holds billing rights; an Admin may not be the billing Owner._

## WHERE: Ecosystem

_Stub — links to: [[Role - Owner]] (the Owner holds billing; Admin holds team management), [[Entity - Team]] (the scope Admin governs), [[System - Plugin Runtime]] (Admins can restrict Plugin access at org level), [[Economy-instance - Plan]] (Admins provision seats within the plan limits the Owner purchased)._
