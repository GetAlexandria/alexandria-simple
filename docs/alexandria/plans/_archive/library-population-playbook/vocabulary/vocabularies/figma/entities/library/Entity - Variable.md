# Variable

## WHAT: Definition

_Stub — a named, typed design token that stores a value (color, number, string, boolean) and can be applied to any Layer property. Variables support modes — multiple value sets that switch together, enabling light/dark theming, density variants, or brand customizations from a single design. Variables are Figma's 2023 entry into the design-token space, offering more semantic power than [[Entity - Style]]s._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Style]] (the predecessor token mechanism; Variables partially supersede Styles for colors and spacing), [[Entity - Library]] (Variables are published via Libraries for cross-File reuse), [[System - Component System]] (Components bind to Variables for dynamic theming), [[Surface - Properties Panel]] (where Variables are bound to Layer properties)._
