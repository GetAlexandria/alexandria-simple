# Connecting

## WHAT: Definition

_Stub — the capability to draw prototype connections between [[Entity - Frame]]s (or between interactive zones within a Frame and destination Frames), defining the interaction flow of a prototype. Connecting is exercised in [[Surface - Prototype Mode]]; the designer selects a source Frame or hotspot and drags a connection arrow to a destination Frame._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Prototype Mode]] (the surface where Connecting is exercised), [[Entity - Frame]] (connections link Frames), [[Capability - Auto Layout]] (Frames with Auto Layout can be connection sources/destinations), [[Pattern - Branch-Merge Workflow]] (prototype connections are tested in branches before merging)._

## WHY: Rationale

_Stub — owner-supplied._

## WHEN: Timeline

_Stub._

## HOW: Specification

_Stub — to be enriched with: connection trigger types (on click, on hover, after delay, on drag, key/gamepad), action types (navigate to, open overlay, scroll to, back), animation settings (dissolve, smart animate, push, slide), and the overflow scrolling configuration._
