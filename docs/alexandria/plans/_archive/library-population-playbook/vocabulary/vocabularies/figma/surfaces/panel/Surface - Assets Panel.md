# Assets Panel

## WHAT: Definition

_Stub — the left-rail panel tab that provides access to [[Entity - Component]]s, [[Entity - Style]]s, [[Entity - Variable]]s, and installed plugins from the current [[Entity - File]] and any subscribed [[Entity - Library]]. Designers drag Components from this panel onto the [[Surface - Canvas]] to insert [[Entity - Instance]]s._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Component]] (browsed and inserted from this panel), [[Entity - Library]] (Library-published Components appear here), [[Surface - Layers Panel]] (the other left-rail tab), [[Capability - Publishing]] (publishing a Library makes Components available here to subscribing Files)._
