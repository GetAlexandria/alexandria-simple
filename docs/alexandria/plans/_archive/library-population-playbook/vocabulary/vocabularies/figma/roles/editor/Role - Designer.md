# Designer

## WHAT: Definition

_Stub — a user with an Editor seat who creates and edits designs. The Designer is Figma's primary role; they author [[Entity - Frame]]s, [[Entity - Component]]s, and prototypes. In Figma's model, the role is implicitly defined by seat type (Editor Seat) rather than by an explicit role title assigned in settings._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Editor Seat]] (the seat that grants editing rights), [[Surface - Canvas]] (the primary working surface), [[Entity - File]] (the container the Designer works in), [[System - Component System]] (the system Designers author into)._
