# Dev Mode

## WHAT: Definition

_Stub — a named mode of the Figma editor optimized for [[Role - Developer]] handoff. In Dev Mode, the [[Surface - Properties Panel]] shows measured values, code snippets (CSS, iOS, Android), and asset export options instead of design editing controls. Dev Mode is accessed via a toggle in the editor toolbar. Figma charges separately for Dev Mode access on some plan tiers (see [[Economy-instance - Dev Mode Seat]])._

_Stub — links to: [[Role - Developer]] (the primary audience for this Surface), [[Economy-instance - Dev Mode Seat]] (the seat type that grants access), [[Surface - Prototype Mode]] (the other mode-Surface; both are accessed from the editor toolbar), [[Entity - Component]] (Component specs and code snippets are the primary content in Dev Mode)._
