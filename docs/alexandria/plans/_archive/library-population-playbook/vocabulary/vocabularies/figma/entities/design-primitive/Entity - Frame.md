# Frame

## WHAT: Definition

_Stub — Figma's term for the top-level structural container on a [[Entity - Page]]. What Sketch calls an Artboard, Figma calls a Frame. A Frame can hold child layers, groups, and other Frames; it supports [[Capability - Auto Layout]] for responsive behavior, clip-content to mask children, and prototype connections to other Frames._

_The naming choice is intentional and diagnostic. "Frame" names the structural role (a boundary, a container) rather than the screen-metaphor ("Artboard" implies a static canvas). This is an aesthetic-named primitive: the word describes what the thing *is* (a frame around content), not the workflow it belongs to. In MDA terms, Frame is a clean aesthetic-first name — it carries no mechanism or process vocabulary, making it neutral across device types and workflow contexts._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Page]] (Frames live on Pages), [[Capability - Auto Layout]] (the capability that makes Frames responsive), [[Entity - Component]] (Components are typically built inside Frames), [[Surface - Canvas]] (the surface Frames inhabit)._
