# Commenting

## WHAT: Definition

_Stub — the capability to add, reply to, and resolve threaded comments pinned to specific locations on the [[Surface - Canvas]]. Both [[Role - Designer]]s (Editor seats) and [[Role - Viewer]]s can add comments. Resolved comments persist but are hidden from the main view. Commenting is the primary async-feedback workflow in Figma._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Canvas]] (comments are pinned to Canvas locations), [[Role - Viewer]] (Viewers can comment without editing), [[Pattern - Comment-Resolve]] (the workflow pattern Commenting enables), [[Surface - Share Modal]] (comment notifications go to collaborators with access)._
