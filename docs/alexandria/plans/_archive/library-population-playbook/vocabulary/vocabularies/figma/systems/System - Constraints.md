# Constraints

## WHAT: Definition

_Stub — the rule-set that governs how a [[Entity - Layer]]'s position and size change when its parent [[Entity - Frame]] resizes. Constraints are the older positional system (pre-dating [[Capability - Auto Layout]]); they describe how each child anchors to its parent's edges (left, right, top, bottom, center, scale, stretch). Constraints remain the primary system for Frames that do not use Auto Layout._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Frame]] (Constraints govern layer behavior when the Frame resizes), [[Entity - Layer]] (Constraints are set per Layer), [[System - Auto Layout Engine]] (Auto Layout supersedes Constraints for most responsive layout work), [[Surface - Properties Panel]] (Constraints are configured in the Constraints section of the Properties Panel)._
