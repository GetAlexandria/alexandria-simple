# Drawing

## WHAT: Definition

_Stub — the capability to create and edit vector shapes and paths on the [[Surface - Canvas]]. Drawing covers shape tools (rectangle, ellipse, polygon, star, line, arrow) and the Pen tool for freeform vector path creation and editing. It is the core creation capability available to [[Role - Designer]]s with an [[Economy-instance - Editor Seat]]._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Canvas]] (where Drawing happens), [[Entity - Layer]] (Drawing creates new Layers), [[Role - Designer]] (the primary role that uses this capability), [[Capability - Auto Layout]] (drawn shapes become the building blocks that Auto Layout organizes)._

## WHY: Rationale

_Stub — owner-supplied._

## WHEN: Timeline

_Stub._

## HOW: Specification

_Stub — to be enriched with: the shape tool shortcuts, Pen tool node types (straight, curved, mirror), vector network behavior, boolean operations (union, subtract, intersect, exclude), and the pencil tool for freehand drawing._
