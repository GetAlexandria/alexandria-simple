# Properties Panel

## WHAT: Definition

_Stub — the right-rail panel that shows and edits properties of the currently selected [[Entity - Layer]]. In design mode, it exposes position, size, fill, stroke, effects, and [[Entity - Style]] bindings. For [[Entity - Component]] [[Entity - Instance]]s, it shows Variant swap controls and local overrides. In [[Surface - Dev Mode]], it shows developer-facing property values and code snippets._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Layer]] (properties shown belong to the selected Layer), [[Entity - Instance]] (Instance swap and override controls appear here), [[Entity - Style]] (Style bindings are set and changed here), [[Entity - Variable]] (Variable bindings are applied here)._
