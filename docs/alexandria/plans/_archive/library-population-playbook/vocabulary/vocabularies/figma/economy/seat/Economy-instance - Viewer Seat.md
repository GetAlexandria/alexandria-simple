# Viewer Seat

## WHAT: Definition

_Stub — the free or low-cost seat tier that grants view-and-comment access to [[Entity - File]]s without editing rights. Users on a Viewer Seat can view designs, add [[Capability - Commenting|comments]], and inspect properties in limited Dev Mode, but cannot create or edit Frames, Components, or Layers. Viewer Seats are Figma's mechanism for broad stakeholder access without billing growth._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Editor Seat]] (the paid tier above), [[Role - Viewer]] (the role that holds this seat), [[Economy-instance - Plan]] (Viewer Seat terms vary by Plan — free on Starter, free-unlimited on Professional), [[Surface - Share Modal]] (the surface through which Viewer Seats are granted)._
