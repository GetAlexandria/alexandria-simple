# Branching

## WHAT: Definition

_Stub — the capability to create a [[Entity - Branch]] from a [[Entity - File]], enabling parallel design work or review flows without editing the main File. A Branch is a full copy of the File at branch time; changes in the Branch can be merged back into the main File via the merge workflow. Branching is the capability; [[Entity - Branch]] is the resulting entity._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Branch]] (the entity this capability creates), [[Entity - File]] (the source File being branched), [[Pattern - Branch-Merge Workflow]] (the workflow Branching enables), [[Capability - Commenting]] (comments in a Branch can be part of the review process before merge)._
