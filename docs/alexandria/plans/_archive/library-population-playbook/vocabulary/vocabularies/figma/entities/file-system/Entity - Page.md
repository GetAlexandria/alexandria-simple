# Page

## WHAT: Definition

_Stub — a named canvas within a [[Entity - File]]. Pages organize design work within a File — common uses include separating flows, breakpoints, design iterations, or handoff notes. Each Page has its own independent [[Surface - Canvas]] with its own [[Entity - Frame]]s and layers._

## WHERE: Ecosystem

_Stub — links to: [[Entity - File]] (the File contains one or more Pages), [[Surface - Canvas]] (each Page renders its own Canvas), [[Entity - Frame]] (Frames live on Pages), [[Surface - Layers Panel]] (the layer hierarchy shown is scoped to the current Page)._
