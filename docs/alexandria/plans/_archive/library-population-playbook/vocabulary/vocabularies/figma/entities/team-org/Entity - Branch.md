# Branch

## WHAT: Definition

_Stub — a parallel copy of a [[Entity - File]] created for exploratory or review editing, analogous to a Git branch. Branches let designers diverge from the main File, make changes, and then merge those changes back — enabling design review workflows without editing the live production file directly. Figma borrowed the Branch/Merge vocabulary directly from version-control software._

_The naming is a deliberate process-vocabulary borrow that worked. Figma's audience includes developers who are deeply familiar with Git, and designers who work alongside them and have absorbed the vocabulary. Branch and Merge are instantly legible to this audience without onboarding — the metaphor transfers because the underlying workflow is parallel: diverge, work, propose, reconcile. This is a textbook case of process-vocabulary borrowing succeeding because the borrower's audience already uses the source vocabulary. Contrast with Linear's deliberate avoidance of Sprint (renamed Cycle) — Linear targets a broader team audience; Figma targets a dev-adjacent design audience._
