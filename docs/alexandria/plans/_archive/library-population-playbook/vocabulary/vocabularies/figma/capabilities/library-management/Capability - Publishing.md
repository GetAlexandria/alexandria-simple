# Publishing

## WHAT: Definition

_Stub — the capability to publish a [[Entity - File]]'s [[Entity - Component]]s, [[Entity - Style]]s, and [[Entity - Variable]]s as a [[Entity - Library]] so that other Files in the [[Entity - Team]] can subscribe and use them. Publishing is the act that converts a regular File into a Library; re-publishing pushes updates to all subscribers. Only [[Role - Designer]]s with edit access can publish._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Library]] (what Publishing creates), [[Entity - Component]] (the primary content being published), [[Entity - Style]] (Styles are published alongside Components), [[Entity - Variable]] (Variables are published for token distribution), [[Pattern - Library Publishing]] (the design-system workflow that uses this capability)._
