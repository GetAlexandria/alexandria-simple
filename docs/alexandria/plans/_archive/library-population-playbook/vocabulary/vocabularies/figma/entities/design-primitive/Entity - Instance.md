# Instance

## WHAT: Definition

_Stub — a placed copy of a [[Entity - Component]] that inherits the Component's properties. Instances can be overridden locally (text, fills, visibility of child layers) without breaking the link to the master Component. When the master Component updates, all Instances reflect the change unless their property was locally overridden._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Component]] (the master this Instance is derived from), [[Entity - Variant]] (Instances can be swapped between Variants of the same Component set), [[Surface - Assets Panel]] (the panel from which designers insert Instances), [[Surface - Properties Panel]] (where Instance overrides are applied)._
