# Dev Mode Seat

## WHAT: Definition

_Stub — a dedicated seat tier introduced to target the [[Role - Developer]] handoff use case at a price point below a full [[Economy-instance - Editor Seat]]. A Dev Mode Seat grants access to [[Surface - Dev Mode]] (code snippets, specs, asset export) without full design-editing capabilities. On some plan tiers, Developer access is included in Editor Seats; on others it is a separate purchasable seat._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Editor Seat]] (the full tier; Dev Mode Seat is a subset of Editor rights), [[Role - Developer]] (the role targeting this seat), [[Surface - Dev Mode]] (the primary surface this seat unlocks), [[Economy-instance - Plan]] (Dev Mode Seat availability and pricing varies by Plan)._
