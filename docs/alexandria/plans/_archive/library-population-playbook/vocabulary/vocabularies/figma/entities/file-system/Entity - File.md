# File

## WHAT: Definition

_Stub — the primary unit of work in Figma. A File contains one or more [[Entity - Page]]s, each of which holds [[Entity - Frame]]s and other design elements. Files live inside [[Entity - Project]]s, which live inside [[Entity - Team]]s. Files are the unit of sharing and collaboration — access is granted at the File level._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Page]] (Pages are children of a File), [[Entity - Project]] (Projects group Files), [[Surface - Canvas]] (the Canvas is the editing surface of a File), [[Surface - Share Modal]] (sharing is configured per File)._
