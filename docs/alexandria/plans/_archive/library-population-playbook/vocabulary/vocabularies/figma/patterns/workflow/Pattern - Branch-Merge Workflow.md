# Branch-Merge Workflow

## WHAT: Definition

_Stub — the design review pattern in which a [[Role - Designer]] creates a [[Entity - Branch]] from a main [[Entity - File]], makes changes in isolation, uses [[Capability - Commenting]] for async review, and then merges the Branch back into the main File. Directly borrowed from software engineering's Git workflow; adapted for design artifacts._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Branch]] (the entity at the center of this workflow), [[Capability - Branching]] (the capability that initiates it), [[Capability - Commenting]] (review within the Branch), [[Pattern - Comment-Resolve]] (the companion pattern for feedback handling within the branch)._
