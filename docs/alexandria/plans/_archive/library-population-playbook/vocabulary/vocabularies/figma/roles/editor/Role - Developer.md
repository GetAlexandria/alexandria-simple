# Developer

## WHAT: Definition

_Stub — a user who primarily consumes designs via [[Surface - Dev Mode]] for handoff. Developers hold Editor seats (or dedicated Dev Mode seats in some plans), but their primary workflow is inspection and code-snippet generation rather than design authoring. Figma treats Developer as an audience category rather than a formal role title in the permission system._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Dev Mode]] (the primary surface for this role), [[Economy-instance - Dev Mode Seat]] (the seat tier targeting this role), [[Entity - Component]] (Developers inspect and extract specs from Components), [[Entity - Frame]] (Developers reference Frames for layout specs)._
