# File Browser

## WHAT: Definition

_Stub — the home screen of Figma where [[Entity - File]]s, [[Entity - Project]]s, [[Entity - Team]]s, and [[Entity - Branch]]es are listed and navigated. The File Browser is the entry point before opening a File and the surface for file management operations (rename, move, duplicate, delete)._

_Stub — links to: [[Entity - File]] (Files are the primary items listed), [[Entity - Project]] (Projects organize Files shown here), [[Entity - Team]] (Teams group Projects shown in the left rail), [[Entity - Branch]] (Branches appear under their parent File)._
