# Library

## WHAT: Definition

_Stub — a [[Entity - File]] that has been published so its [[Entity - Component]]s, [[Entity - Style]]s, and [[Entity - Variable]]s are available for use in other Files. A Library is not a separate object type — it is a File in a publishing state. Teams maintain one or more Libraries as the source of truth for their design system: brand colors as Styles, tokens as Variables, reusable UI elements as Components._

_Important disambiguation: Figma's Library is a component library in the design-system sense — a published collection of reusable design primitives. This is categorically distinct from Alexandria's Library concept, which is a knowledge wiki for product documentation. When comparing vocabulary across products for a director, this polysemy must be flagged explicitly: "Library" means design-primitive-publishing here; it means knowledge-base there. The surface similarity masks a deep conceptual difference._
