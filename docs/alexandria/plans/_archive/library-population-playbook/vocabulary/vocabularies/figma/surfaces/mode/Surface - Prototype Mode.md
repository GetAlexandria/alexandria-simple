# Prototype Mode

## WHAT: Definition

_Stub — a named editing state of the Figma editor in which the [[Surface - Properties Panel]] switches to prototype-connection controls and connection arrows between [[Entity - Frame]]s are visible on the [[Surface - Canvas]]. Designers use Prototype Mode to draw flow connections and set interaction triggers and transitions; they switch to Prototype Mode by clicking the "Prototype" tab in the Properties Panel._

_Prototype Mode is a Surface that is also a mode — a state the editor is in rather than a separate destination. This places it in the same structural family as Claude Code's Plan Mode or other tools' "mode" concepts: a named UI state that gates a distinct capability set. The relevant diagnostic: when cataloguing a product's Surfaces, a mode that substantially reconfigures the UI and enables a gated capability set should be named and catalogued as its own Surface, not just as a panel tab._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Frame]] (Frames are the nodes connected in Prototype Mode), [[Capability - Connecting]] (the capability exercised in this Mode), [[Surface - Canvas]] (the Canvas shows connection arrows when Prototype Mode is active), [[Surface - Dev Mode]] (the other major mode-Surface in the editor)._
