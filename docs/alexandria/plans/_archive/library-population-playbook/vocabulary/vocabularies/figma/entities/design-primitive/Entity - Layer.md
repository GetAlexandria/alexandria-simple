# Layer

## WHAT: Definition

_Stub — the atomic visual object in Figma's [[Entity - Page]]. Every visible element — text, rectangle, image, vector, component instance — is a Layer. Layers nest into a tree; the [[Surface - Layers Panel]] exposes that tree. Layers are the unit of selection, styling, and export._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Layers Panel]] (the panel that shows the full layer tree), [[Entity - Frame]] (Frames are top-level Layers and containers for child Layers), [[Entity - Group]] (Groups collect Layers), [[Entity - Component]] (Components are named Layers reused across the File)._
