# Plan

## WHAT: Definition

_Stub — the subscription tier a [[Entity - Team]] operates on, which determines seat limits, feature access, and per-[[Economy-instance - Editor Seat]] pricing. Figma's current plan ladder: Starter (free, limited seats and files), Professional (per-Editor-Seat monthly), Organization (org-wide seat management, SSO, advanced controls), Enterprise (enterprise security, admin controls, SLA). The Plan is subscribed to by the [[Role - Owner]] and governs what the whole Team can access._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Editor Seat]] (the billable unit the Plan prices), [[Economy-instance - Viewer Seat]] (Viewer terms differ by Plan), [[Economy-instance - Dev Mode Seat]] (Dev Mode access terms differ by Plan), [[Role - Owner]] (the Owner subscribes to and changes the Plan), [[Entity - Team]] (the Plan is attached to a Team)._
