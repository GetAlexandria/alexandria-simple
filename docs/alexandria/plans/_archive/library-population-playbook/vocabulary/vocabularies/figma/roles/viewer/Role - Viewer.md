# Viewer

## WHAT: Definition

_Stub — a user with a Viewer seat who can view files and add comments but cannot edit designs. Viewers are the lowest-permission seat tier; they are often stakeholders, reviewers, or clients who need visibility into designs without the ability to change them._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Viewer Seat]] (the seat type that defines this role), [[Capability - Commenting]] (the key capability Viewers can exercise), [[Entity - File]] (Viewers access Files in read-only mode), [[Surface - Share Modal]] (how Files are shared with Viewers)._
