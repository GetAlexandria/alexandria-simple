# Project

## WHAT: Definition

_Stub — a named folder within a [[Entity - Team]] that organizes [[Entity - File]]s. Projects group Files by product area, initiative, or workflow. Access to a Project can be scoped separately from the broader Team membership, enabling partial-access patterns within a Team._
