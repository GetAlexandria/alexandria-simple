# Share Modal

## WHAT: Definition

_Stub — the dialog that controls access to a [[Entity - File]] or prototype. From the Share Modal, users invite collaborators by email, set link-access levels (Anyone with the link / Restricted), and copy shareable links. The Share Modal is the primary surface where [[Role - Viewer]] access is granted._

## WHERE: Ecosystem

_Stub — links to: [[Entity - File]] (sharing is configured per File), [[Role - Viewer]] (Viewer access is granted here), [[Role - Designer]] (Editors can be invited here), [[Economy-instance - Viewer Seat]] (Viewers accessing via link consume or skip seats depending on plan)._
