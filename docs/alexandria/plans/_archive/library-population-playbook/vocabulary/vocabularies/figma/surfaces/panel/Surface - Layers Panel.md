# Layers Panel

## WHAT: Definition

_Stub — the left-rail panel that displays the [[Entity - Layer]] hierarchy for the current [[Entity - Page]]. It shows the tree of Frames, Groups, Components, and leaf Layers in the order they stack on the [[Surface - Canvas]]. Clicking a Layer in the panel selects it; dragging reorders it._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Layer]] (the objects the panel lists), [[Entity - Page]] (the panel is scoped to the current Page), [[Surface - Canvas]] (selection in the panel selects on the Canvas and vice versa), [[Surface - Assets Panel]] (the Assets tab is accessible from the same left-rail position)._
