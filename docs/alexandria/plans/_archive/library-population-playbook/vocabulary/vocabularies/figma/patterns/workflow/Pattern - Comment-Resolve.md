# Comment-Resolve

## WHAT: Definition

_Stub — the async feedback pattern in which collaborators add comments to specific locations on the [[Surface - Canvas]], discuss via threaded replies, and the designer marks each comment resolved when the feedback is addressed. Resolved comments collapse out of the active view, providing a clean signal of review progress without deleting the audit trail._

## WHERE: Ecosystem

_Stub — links to: [[Capability - Commenting]] (the capability this pattern uses), [[Surface - Canvas]] (where comments are pinned), [[Pattern - Branch-Merge Workflow]] (Comment-Resolve typically runs inside a Branch before merge), [[Role - Viewer]] (Viewers participate as commenters without editing access)._
