# Variant Matrix

## WHAT: Definition

_Stub — the design-system practice of organizing all [[Entity - Variant]]s of a [[Entity - Component]] into a grid, where each dimension of variation (Type, Size, State) is a row or column. The matrix makes every combination of properties visible at once, ensuring no state is missed in the design specification. The Variant Matrix is the standard organizational form Figma uses to present Component sets in the editor._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Variant]] (the objects the matrix contains), [[Entity - Component]] (the master concept the matrix documents), [[Surface - Assets Panel]] (where Component sets are browsed, showing the matrix view), [[Pattern - Component Override]] (overrides select a specific cell of the matrix per Instance)._
