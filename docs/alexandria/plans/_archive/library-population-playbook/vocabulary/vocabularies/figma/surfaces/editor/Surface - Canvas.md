# Canvas

## WHAT: Definition

_Stub — the infinite two-dimensional editing surface that fills the center of the Figma editor. Each [[Entity - Page]] has its own Canvas. Designers place [[Entity - Frame]]s, [[Entity - Group]]s, and [[Entity - Layer]]s on the Canvas; zoom and pan to navigate; and select objects by clicking or dragging. The Canvas is Figma's primary workspace._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Page]] (each Page has one Canvas), [[Entity - Frame]] (Frames are placed on the Canvas), [[Surface - Layers Panel]] (the Layers Panel reflects the Canvas's layer tree), [[Surface - Properties Panel]] (the Properties Panel shows properties of the Canvas selection)._
