# Alignment Sweep

## WHAT: Definition

_Stub — the Alignment Sweep is the recurring cycle through which the Director maintains structural health without performing the maintenance themselves. The library detects its own drift, surfaces a structured report, asks the Director for judgment on ambiguous cases, executes approved repairs, and returns quieter on the next cycle. Each cycle, the Director approves fewer fixes as the library stabilizes. The full existing card is at [[Loop - Alignment Sweep]] in the existing library._
