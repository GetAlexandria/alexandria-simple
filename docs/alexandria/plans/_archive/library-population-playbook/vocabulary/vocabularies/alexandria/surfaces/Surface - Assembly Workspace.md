# Assembly Workspace

## WHAT: Definition

_Stub — the Assembly Workspace is the nested section within the Library Boundary where Bridget assembles context briefings. This is where the ten-step assembly procedure runs: task classification, retrieval profile loading, graph traversal, seed card expansion, mandatory category checking, briefing writing, and provenance logging. The Assembly Workspace is a read-only consumer of library content and a write-only producer of briefings — it never modifies the cards it reads. The full existing card is at [[Section - Assembly Workspace]] in the existing library._
