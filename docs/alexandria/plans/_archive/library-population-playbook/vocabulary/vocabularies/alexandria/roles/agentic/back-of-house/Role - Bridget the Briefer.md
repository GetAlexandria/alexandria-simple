# Bridget the Briefer

## WHAT: Definition

_Stub — the assembly interface Agent between the library and the factory's AI consumers. Bridget is an outward-facing library role — the Factory Boundary counterpart to Raven's Human Boundary. She faces two directions: toward the library (reading cards, traversing the graph) and toward the factory (delivering briefings that help builder agents make aligned decisions). Bridget ASSEMBLES; does not grade, write cards, answer product questions for humans, or triage signal. Named for the Irish lore of Bridget as a keeper of knowledge and a bridge between worlds. The full agent definition lives at [[Agent - Bridget the Briefer]] in the existing library._
