# Retrieval and Assembly Engine

## WHAT: Definition

_Stub — the Retrieval and Assembly Engine transforms a task description into a context briefing by navigating the knowledge graph. It operates through retrieval profiles (typed instructions for graph traversal per card type) combined with graph traversal (seed selection, hop-depth expansion, mandatory category checks) to produce assembled briefings with U-shaped attention ordering and card budgets. Evidence status: pre-validation — the retrieval profile concept and attention ordering hypothesis are directional bets, not yet prototype-tested at scale. The full system card is at [[System - Retrieval and Assembly Engine]] in the existing library._
