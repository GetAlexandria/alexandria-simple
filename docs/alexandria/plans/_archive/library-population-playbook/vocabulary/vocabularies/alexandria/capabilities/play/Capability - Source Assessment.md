# Source Assessment

## WHAT: Definition

_Stub — Source Assessment is Conan's Job 0: auditing source material for five-dimension coverage before any cards are built. Conan evaluates whether source files contain enough WHAT, WHERE, WHY, HOW, and WHEN to produce quality cards. Output is a readiness classification: READY (proceed), GAPS (proceed with caution), or BLOCKED (stop — critical dimensions missing). Source Assessment gates the entire library construction pipeline. The full capability card is at [[Capability - Source Assessment]] in the existing library._

_Stub — links to: [[Capability - Source Assessment]] (full card), [[Role - Conan the Librarian]] (executor), [[Surface - Card Repository]] (downstream target), [[Capability - Inventory]] (follows Source Assessment in the pipeline)._

## WHY: Rationale

_Stub — owner-supplied. Source Assessment prevents hollow cards: a card built from insufficient source material cannot satisfy the five-dimension quality rubric, and no amount of post-hoc grading will fix it._
