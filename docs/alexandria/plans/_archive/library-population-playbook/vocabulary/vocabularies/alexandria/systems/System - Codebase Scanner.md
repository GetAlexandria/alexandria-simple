# Codebase Scanner

## WHAT: Definition

_Stub — the Codebase Scanner performs progressive, two-tier investigation of a project's file tree to discover domain nouns, architectural patterns, and system boundaries. Tier 1 reads only the file tree (directory names, file names, folder nesting) to form candidate hypotheses. Tier 2 selectively reads file contents for high-signal candidates to confirm or refine hypotheses. Uses framework-agnostic directory-pattern heuristics. Output is structured proposals with confidence levels (High, Medium, Speculative). The scanner proposes; the Director decides. The full system card is at [[System - Codebase Scanner]] in the existing library._
