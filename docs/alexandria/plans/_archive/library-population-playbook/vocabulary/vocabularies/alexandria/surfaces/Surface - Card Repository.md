# Card Repository

## WHAT: Definition

_Stub — the Card Repository is the nested workspace within the Library Interior where all library cards live. It is the typed-folder structure that encodes the taxonomy: `library/rationale/` for Standards, Principles, and Product Theses; `library/product/` for Agents, Systems, Capabilities, Domains, Sections, and all other product-layer types; `library/experience/` for Loops, Journeys, Goals, and Forces. Sam builds here. `alxndr lint` sweeps here. Conan grades here. The Card Repository is simultaneously a filesystem location and the physical substrate of the Knowledge Graph. The full existing card is at [[Section - Card Repository]] in the existing library._
