# Provenance Log

## WHAT: Definition

_Stub — the Provenance Log records what happened during each context assembly: which cards were retrieved, which searches were run, which decisions were made, and what the outcome was. Every assembly session is logged to `provenance-log.jsonl`. The log feeds provenance analytics — usage metrics, gap frequency, card retrieval patterns — that inform retrieval profile tuning and library maintenance priorities. Together with the Feedback Queue (what should improve) and the Signal Queue (what is contested), the Provenance Log forms the library's operational memory. The full system card is at [[System - Provenance Log]] in the existing library._
