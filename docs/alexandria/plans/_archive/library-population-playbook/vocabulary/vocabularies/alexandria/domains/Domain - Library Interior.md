# Library Interior

## WHAT: Definition

_Stub — the Library Interior is the top-level workspace where all knowledge construction and quality assurance happens. This is where Conan evaluates, diagnoses, and plans; where Sam builds and fixes cards; and where `alxndr lint` sweeps for structural defects. Every operation that changes the library's content takes place inside this domain. The Interior is the building-metaphor "inside" — agents working here are consciously inside the library as distinct from working at the boundary. The full domain card is at [[Domain - Library Interior]] in the existing library._
