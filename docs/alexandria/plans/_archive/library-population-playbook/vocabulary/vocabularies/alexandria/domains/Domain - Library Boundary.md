# Library Boundary

## WHAT: Definition

_Stub — the Library Boundary is the top-level workspace where the library meets the factory and the outside world. Two agents operate here: Bridget (facing the factory — Library Boundary toward machines) and Raven/Solomon (facing humans — Library Boundary toward humans). The Boundary is the distinct territory between the library's knowledge graph and whatever the factory or human on the other side needs. The full domain card is at [[Domain - Library Boundary]] in the existing library._

## WHERE: Ecosystem

_Stub — links to: [[Domain - Library Boundary]] (full card), [[Domain - Library Interior]] (the sibling domain), [[Role - Bridget the Briefer]] (factory-facing Boundary agent), [[Role - Raven the Maven]] (human-facing Boundary agent), [[Role - Solomon the Sentinel]] (human-facing Boundary agent)._

## WHY: Rationale

_Stub — owner-supplied. The Boundary concept is essential because it cleanly separates "what happens inside the library" from "what happens when the library meets the world." Without this distinction, the library becomes a general-purpose tool that does everything — it loses its identity as a specifically bounded knowledge system._
