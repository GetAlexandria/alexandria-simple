# Gap Analysis Engine

## WHAT: Definition

_Stub — the Gap Analysis Engine compares the Wizard Configuration Engine's tier assignments against existing library state to produce scored, sequenced gaps. The core formula is `priority_score = tier_weight × gap_severity × freshness_penalty`. The engine answers "what do you need that you don't have?" — not "what do you need?" (the Wizard answers that). Output is a phased seeding sequence: Foundation gaps first, then Core, then Amplifier — gaps ordered by priority score within each phase. The full system card is at [[System - Gap Analysis Engine]] in the existing library._
