# Maintainer

## WHAT: Definition

_Stub — Alexandria's developers: the engineers who build and ship the Alexandria plugin, CLI, and agent infrastructure. Maintainers interact with the codebase, write skills, run evals, and cut releases. They are end users of the same agent team (Raven, Conan, Sam) that Directors use — but they also own the implementation that Directors run on top of. This is the unified-corpus signature in practice: Maintainers and Directors share vocabulary because they share the same library._
