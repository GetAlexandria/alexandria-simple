# Cascade Analysis

## WHAT: Definition

_Stub — Cascade Analysis is Conan's capability to trace quality issues or strategic changes downstream through the knowledge graph to calculate blast radius. The analysis distinguishes symptoms (a downstream card is weak) from root causes (the upstream thesis it links to is a stub). Cascade Analysis transforms a list of weak cards into a prioritized fix plan ordered by impact. The full capability card is at [[Capability - Cascade Analysis]] in the existing library._
