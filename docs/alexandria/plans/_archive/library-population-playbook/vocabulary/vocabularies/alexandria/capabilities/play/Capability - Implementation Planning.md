# Implementation Planning

## WHAT: Definition

_Stub — Implementation Planning is a skill-based capability that takes a product goal and a context library, runs a multi-step planning conversation with the Director, and produces dependency-ordered tickets and success outcomes plus a release summary document. It is the first capability that orchestrates multiple agents within a single conversational workflow: the planner invokes Bridget for context assembly (Step 2) and produces library-updates.md for Conan's review (Step 8). The full capability card is at [[Capability - Implementation Planning]] in the existing library._
