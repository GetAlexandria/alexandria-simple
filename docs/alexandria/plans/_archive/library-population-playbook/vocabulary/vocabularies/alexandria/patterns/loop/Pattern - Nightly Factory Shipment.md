# Nightly Factory Shipment

## WHAT: Definition

_Stub — the Nightly Factory Shipment is the daily build cadence through which Alexandria is incrementally improved. Each build day, one governing question: "What single thing, shipped tonight, most reduces friction for a newly-onboarded user?" The loop runs two parallel tracks — Option A (first-loop friction reduction, always primary) and Option B (known-bad backlog burn-down, only when A is satisfied) — and produces one scoped ship at the end of each day. The full existing card is at [[Loop - Nightly Factory Shipment]] in the existing library._
