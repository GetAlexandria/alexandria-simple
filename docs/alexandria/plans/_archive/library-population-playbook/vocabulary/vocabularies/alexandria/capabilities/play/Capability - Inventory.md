# Inventory

## WHAT: Definition

_Stub — Inventory is Conan's Job 1: reading assessed source material and producing a manifest of every card that should exist in the library. The manifest specifies each card's type, source reference, build order, and classification rationale. It is the contract between the agents: Sam builds to the manifest, Conan grades against it. The full capability card is at [[Capability - Inventory]] in the existing library._
