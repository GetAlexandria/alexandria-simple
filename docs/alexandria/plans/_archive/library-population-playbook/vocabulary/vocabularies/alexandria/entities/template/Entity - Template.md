# Template

## WHAT: Definition

_Stub — a Template is a reusable shape that defines the spatial arrangement of a structured output. Alexandria has three Templates: Card (the five-section WHAT/WHERE/WHY/WHEN/HOW structure all cards follow), Context Briefing (the five-region structure Bridget assembles into), and Implementation Plan (the three-part directory structure for planning output). Templates define structure; they do not contain content. They are the contracts that make later modules (Grading, Linting, Assembly) mechanically checkable._
