# Admin

## WHAT: Definition

_Stub — the [[Role - Merchant]]'s Shopify dashboard; the primary management surface for the [[Entity - Shop]]. The Admin is where the Merchant manages [[Entity - Product|Products]], [[Entity - Order|Orders]], [[Entity - Customer|Customers]], [[Domain - Payments|Payments]], and [[Domain - Marketing|Marketing]]. Admin access is available to the Merchant and authorized [[Role - Staff]] members. The Admin is the primary surface for all merchant-side nouns._

## WHERE: Ecosystem

_Stub — links to: [[Role - Merchant]] (primary user), [[Role - Staff]] (secondary user, scoped by permissions), [[Entity - Shop]] (the Shop this Admin manages), all domain areas (Catalog, Fulfillment, Payments, Marketing)._

_Stub — to be enriched with: Admin navigation structure (Home, Orders, Products, Customers, Analytics, Marketing, Discounts, Apps, Settings); mobile Admin app; Admin API (the programmatic interface to the same data); Staff permission scoping within the Admin; embedded Apps (third-party surfaces rendered within Admin's chrome)._
