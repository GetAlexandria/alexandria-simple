# Discount

## WHAT: Definition

_Stub — the [[Role - Merchant]]'s price-reduction tool: a named reduction applied to a [[Entity - Cart]] total, specific line items, or shipping. Discounts are created in the [[Surface - Admin]] and take effect either via a code the shopper enters at [[Entity - Checkout]] or automatically when qualifying conditions are met. Discounts are a primary marketing and conversion lever._

## WHERE: Ecosystem

_Stub — links to: [[Capability - Applying a Discount]] (the Capability that activates this Economy-instance), [[Entity - Cart]] (the Cart total being reduced), [[Entity - Checkout]] (where code-based discounts are entered), [[Domain - Marketing]] (the domain that owns Discount strategy)._
