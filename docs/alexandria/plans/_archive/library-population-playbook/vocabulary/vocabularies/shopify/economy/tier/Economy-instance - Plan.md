# Plan

## WHAT: Definition

_Stub — the [[Role - Merchant]]'s billing tier on Shopify's platform. Plans determine which features are available (advanced reporting, carrier-calculated shipping, third-party payment gateway fee rates, [[Role - Staff]] account limits, API rate limits) and set the monthly or annual platform fee. The current tier structure is: Basic / Shopify / Advanced / Plus / Enterprise (Shopify Commerce Components). Transaction fees decrease at higher tiers._

_Stub — links to: [[Role - Merchant]] (the Plan holder), [[Entity - Shop]] (Plan is a Shop-level attribute), [[Economy-instance - Discount]] (discount functionality varies by Plan), [[Role - Staff]] (Staff account limits are Plan-gated)._
