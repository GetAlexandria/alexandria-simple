# Filtering

## WHAT: Definition

_Stub — constraining a [[Surface - Database View]] to show only rows where one or more [[Entity - Property]] values match specified predicates. Filters are configured per [[Surface - Database View]] and do not affect the underlying data — they only change which rows the View displays. Filters can be combined with AND/OR logic and can be set as either persistent View filters (shared by all users of that View) or temporary personal filters (applying only to the current user's session)._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Database View]] (Filtering is configured and applied per View), [[Entity - Property]] (Filter predicates are defined against Property values), [[Capability - Sorting]] (Sorting and Filtering are configured together in the View settings), [[Pattern - Linked Database]] (Linked Databases embed pre-filtered Views)._
