# Mentioning

## WHAT: Definition

_Stub — creating an active reference within a [[Entity - Page]] body or comment by typing "@" followed by the name of a [[Role - Member]], [[Entity - Page]], [[Entity - Database]], or a date. A Person mention generates a notification to the mentioned Member. A Page mention creates a clickable link to the referenced Page. A Date mention can be set as a reminder. Mentions are a Notion-wide linking mechanism that turns prose text into a connected graph of references._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Comments]] (Mentions appear frequently in Comments to direct notifications), [[Entity - Page]] (Page mentions create inter-Page links), [[Role - Member]] (Person mentions notify Members), [[Entity - Block]] (Mentions are inline elements within a text Block), [[Surface - Page View]] (Mentions are authored in the Page View editor)._
