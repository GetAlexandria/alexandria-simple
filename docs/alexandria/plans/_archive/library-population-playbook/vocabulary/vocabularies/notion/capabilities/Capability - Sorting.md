# Sorting

## WHAT: Definition

_Stub — ordering the rows in a [[Surface - Database View]] by one or more [[Entity - Property]] values. Sorts are configured per View and do not modify the underlying data. Multiple sorts can be stacked (sort first by Status, then by Due Date). Sort direction is ascending or descending; available sort orders depend on the Property type (alphabetical for Text, chronological for Date, numerical for Number, etc.)._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Database View]] (Sorting is configured and applied per View), [[Entity - Property]] (Sort keys are Properties), [[Capability - Filtering]] (Sorting and Filtering are configured together in the View settings panel)._
