# Database as Application

## WHAT: Definition

_Stub — the pattern of using a [[Entity - Database]] combined with [[Surface - Database View]]s, [[Entity - Property]] schema, [[Entity - Relation]]s, [[Entity - Rollup]]s, and [[Entity - Template]]s to build a custom CRUD application. A user building a content calendar, a bug tracker, a CRM, or a hiring pipeline in Notion is executing this pattern: the Database is the data store, Views are the query layer, Properties are the schema, and Templates ensure consistent row creation. No code is written; the application is assembled from Notion's built-in primitives._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Database]] (the data layer of this pattern), [[Surface - Database View]] (the query/display layer), [[Entity - Property]] (the schema layer), [[Entity - Relation]] (cross-Database joins), [[Entity - Rollup]] (computed aggregations), [[Entity - Template]] (standardized row creation), [[Pattern - Linked Database]] (Linked Databases compose multiple Database-as-Application instances)._
