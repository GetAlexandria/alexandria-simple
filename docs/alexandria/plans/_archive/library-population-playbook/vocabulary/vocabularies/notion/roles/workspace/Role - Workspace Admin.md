# Workspace Admin

## WHAT: Definition

_Stub — a Member with elevated configuration rights across the Workspace, delegated by the [[Role - Workspace Owner]]. Admins can manage Members and Guests, configure Teamspaces, set security and SAML SSO settings, and audit content — but cannot manage billing or delete the Workspace._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Workspace]] (the scope of Admin authority), [[Role - Workspace Owner]] (the Role that grants Admin status), [[Role - Member]] (Admins are Members with elevated rights), [[System - Permission Model]] (Admins sit below Owners in the permission hierarchy)._
