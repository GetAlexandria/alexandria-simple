# Database View

## WHAT: Definition

_Stub — the multi-layout rendering surface for a [[Entity - Database]]. A Database View applies a layout, a Filter set, a Sort order, and visible Properties to display the Database's rows. Multiple Views can be created for the same Database, each with its own configuration — a Database might have a Table View for data entry, a Board View for status tracking, and a Calendar View for deadline management, all showing the same underlying rows. The five named View layout modes are: **Table** (spreadsheet grid), **Board** (Kanban by a Select Property), **Calendar** (by a Date Property), **Gallery** (card grid with page cover or image), **List** (simplified row list), and **Timeline** (Gantt-style by date range Properties)._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Database]] (Database Views render a Database), [[Entity - Property]] (Views display and filter by Properties), [[Capability - Filtering]] (Filters are configured per View), [[Capability - Sorting]] (Sorts are configured per View), [[Pattern - Linked Database]] (a Linked Database embeds a filtered View of a Database inside a Page)._
