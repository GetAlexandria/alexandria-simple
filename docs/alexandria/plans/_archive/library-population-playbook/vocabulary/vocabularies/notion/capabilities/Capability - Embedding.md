# Embedding

## WHAT: Definition

_Stub — inlining another [[Entity - Page]], [[Entity - Database]], or external content as a [[Entity - Block]] within a [[Entity - Page]]. Embedding takes three forms: (1) Sub-page embed — a [[Entity - Sub-page]] appears inline as a named block that opens the child Page; (2) Linked Database embed — a [[Entity - Database]] is rendered as an inline [[Surface - Database View]] block within another Page (see [[Pattern - Linked Database]]); (3) External embed — a URL from a supported third-party service (Figma, Google Maps, Twitter/X, YouTube, Loom, etc.) is rendered as an interactive iframe Block within the Page._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Block]] (Embeds are Block types), [[Entity - Page]] (Embedding is performed within a Page), [[Entity - Database]] (Databases can be embedded via Linked Database), [[Pattern - Linked Database]] (the canonical Database-within-Page embedding pattern), [[System - Block Tree]] (embedded Blocks are nodes in the Block tree)._
