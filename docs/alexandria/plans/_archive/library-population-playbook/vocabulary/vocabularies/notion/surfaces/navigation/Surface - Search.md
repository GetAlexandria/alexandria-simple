# Search

## WHAT: Definition

_Stub — the universal search surface, invoked via Cmd+K (Mac) or Ctrl+K (Windows). The Search surface provides full-text search across all [[Entity - Page]]s and [[Entity - Database]] entries the current user has access to in the [[Entity - Workspace]]. Results appear in a modal overlay as the user types; results include Page titles, Database row titles, and text matches within page bodies. Search also surfaces recently visited Pages and supports navigation commands (jump to a Page, create a new Page)._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Page]] (Pages are the primary search result type), [[Entity - Database]] (Database rows surface as Page results), [[Surface - Sidebar]] (Search is invoked from the Sidebar top area), [[Entity - Workspace]] (Search scope is the Workspace the user is in)._
