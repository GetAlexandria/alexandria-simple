# Sidebar

## WHAT: Definition

_Stub — the left-rail navigation surface showing the [[Entity - Workspace]] structure. The Sidebar displays: the Workspace name and switcher (top), [[Entity - Teamspace]] sections (each a labeled, collapsible group of Pages), a Favorites section (user-pinned Pages), a Recent section (recently visited Pages), a Private section (Pages visible only to the current user), and the Trash. Users navigate to any [[Entity - Page]] by expanding the tree in the Sidebar, which renders [[Entity - Sub-page]] hierarchies as nested indented entries._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Teamspace]] (each Teamspace appears as a labeled section), [[Entity - Page]] (Pages are the items in the Sidebar tree), [[Entity - Sub-page]] (Sub-pages appear nested within their parent), [[Capability - Search]] (Search is invoked from the Sidebar's top area via Cmd+K)._
