# Member

## WHAT: Definition

_Stub — a user with full access to the Workspace; consumes a billable seat. Members can view, edit, comment on, and create content across any Teamspace or Page they are granted access to. Members are added by invitation and are visible in the Workspace's member directory._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Workspace]] (the boundary within which Member access applies), [[Entity - Teamspace]] (Members belong to one or more Teamspaces), [[Economy-instance - Seat]] (each Member consumes one seat), [[Role - Guest]] (the contrasting role — per-page access, no seat consumed), [[System - Permission Model]] (Member is the baseline access level for full Workspace participants)._
