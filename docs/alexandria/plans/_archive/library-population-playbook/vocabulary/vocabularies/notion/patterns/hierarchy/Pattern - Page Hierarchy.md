# Page Hierarchy

## WHAT: Definition

_Stub — the organizational pattern of nesting [[Entity - Sub-page]]s inside [[Entity - Page]]s indefinitely, creating a tree structure used as the primary information architecture for a Notion [[Entity - Workspace]]. The Page Hierarchy appears in the [[Surface - Sidebar]] as a collapsible tree; users navigate by expanding sections. Teams use this pattern to organize knowledge: Company → Department → Project → Meeting Notes, or Product → Feature → Spec → Decision Log. Depth is unlimited._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Page]] (the nodes in the hierarchy), [[Entity - Sub-page]] (the nesting mechanism), [[Surface - Sidebar]] (the primary rendering surface for the hierarchy), [[System - Permission Model]] (permissions cascade down the hierarchy), [[Entity - Teamspace]] (Teamspaces are the top-level anchor points for hierarchies within a Workspace)._
