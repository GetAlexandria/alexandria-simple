# Sub-page

## WHAT: Definition

_Stub — a [[Entity - Page]] nested inside another Page. Sub-pages are created by adding a "Child page" Block inside any Page body. The hierarchy depth is unlimited: a Sub-page can itself contain Sub-pages, and so on. Sub-pages appear both inline in the parent Page (as a named Block) and in the Sidebar as nested entries beneath their parent._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Page]] (a Sub-page is a Page with a parent Page), [[System - Block Tree]] (Sub-pages are represented as child-page Blocks within the parent's Block tree), [[Surface - Sidebar]] (the Sidebar renders the Sub-page hierarchy as a collapsible tree), [[Pattern - Page Hierarchy]] (the organizing Pattern built from Sub-page nesting), [[System - Permission Model]] (Sub-pages inherit parent Page permissions unless explicitly restricted)._
