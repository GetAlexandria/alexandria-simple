# Page

## WHAT: Definition

_Stub — the document primitive and the single most fundamental noun in Notion. A Page is a named, addressable unit of content composed of [[Entity - Block]]s arranged vertically. Every piece of content a user creates or encounters in Notion is a Page: wikis, notes, meeting notes, project briefs, roadmaps — all Pages. A Page can contain other Pages as sub-pages (see [[Entity - Sub-page]]), and can itself be contained in a Teamspace or another Page._

_Page is also the unit of record in a [[Entity - Database]]: every row in a Database is itself a Page with a title and body. This duality — Page as stand-alone document AND Page as queryable database row — is the load-bearing cut that defines Notion's identity in the `families.md` "Document vs Record" axis. The same noun carries both roles; the context (is this Page living inside a Database?) determines which reading applies. New users routinely discover this duality as a revelation: the Database they built to track projects turns out to contain full Pages, each of which can hold a body, sub-pages, linked databases, and the full Block composition affordances of any other Page._
