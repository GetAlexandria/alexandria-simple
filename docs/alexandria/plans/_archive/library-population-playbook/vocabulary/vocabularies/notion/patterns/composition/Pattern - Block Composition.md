# Block Composition

## WHAT: Definition

_Stub — the pattern of assembling a [[Entity - Page]] from heterogeneous [[Entity - Block]] types to create rich, structured content. A single Page might combine heading Blocks, paragraph Blocks, a callout Block, a toggle Block containing a sub-list, an image Block, an inline database Block, and a [[Entity - Sub-page]] Block — all arranged vertically and reorderable by drag-and-drop. Block Composition is how Notion replaces traditional rich-text-editor authoring: instead of formatting a monolithic document, the user assembles a document from discrete, typed, independently manipulable units._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Block]] (the unit of composition), [[Entity - Page]] (the surface on which composition happens), [[System - Block Tree]] (the underlying structure that Block Composition produces), [[Surface - Page View]] (the editor surface where composition is performed), [[Entity - Template]] (Templates are reusable Block Compositions)._
