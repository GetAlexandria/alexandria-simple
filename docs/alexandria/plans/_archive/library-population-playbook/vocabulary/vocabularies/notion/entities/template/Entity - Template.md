# Template

## WHAT: Definition

_Stub — a reusable [[Entity - Page]] or [[Entity - Block]] structure that can be instantiated to create new content following a predefined layout. Templates exist at two levels: (1) Database Templates — a preconfigured [[Entity - Page]] layout applied to new rows in a [[Entity - Database]], so every new row starts with the same Properties pre-filled and the same Block structure in the body; (2) Template Buttons — a [[Entity - Block]] that generates a copy of a defined Block structure when clicked, useful for repeating layouts within a Page (e.g., a meeting notes template button that inserts a dated section)._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Page]] (Templates produce Pages), [[Entity - Database]] (Database Templates are defined per-Database), [[Entity - Block]] (Template Buttons are a Block type; templates define Block structures), [[Surface - Page View]] (the Template gallery is accessed from the New Page flow)._
