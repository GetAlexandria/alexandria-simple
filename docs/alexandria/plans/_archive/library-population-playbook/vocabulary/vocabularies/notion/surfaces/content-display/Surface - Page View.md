# Page View

## WHAT: Definition

_Stub — the single-page rendering and editing surface. When a user opens a [[Entity - Page]], they see the Page View: the page icon and cover image (optional), the page title, and the vertically stacked list of [[Entity - Block]]s that make up the page body. Blocks are editable inline; new Blocks are added via the "/" slash command or by pressing Enter. The Page View is the primary authoring surface in Notion._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Page]] (the object this surface renders), [[Entity - Block]] (Blocks are the units displayed and edited within the Page View), [[Surface - Sidebar]] (the Sidebar navigates to a Page View), [[Surface - Comments]] (page-level comments appear in the Page View), [[Surface - Database View]] (when a page is a Database row, its Page View also shows the Property metadata panel)._
