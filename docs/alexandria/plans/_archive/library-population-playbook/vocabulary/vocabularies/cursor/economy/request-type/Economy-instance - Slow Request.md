# Slow Request

## WHAT: Definition

_Stub — an unlimited but throttled model invocation available after the Developer's Fast Request quota is exhausted (or as a default choice for less latency-sensitive work). Slow Requests use capable but less premium models or apply rate limiting, and are available without a hard monthly cap. The Slow/Fast split is Cursor's primary economy noun: it makes the two-tier quality tradeoff explicit without hiding it behind opaque "credits" terminology._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Fast Request]] (the premium alternative Slow Requests complement), [[Economy-instance - Plan]] (the Plan determines whether Slow Requests are the default or the fallback after Fast Request quota exhaustion)._
