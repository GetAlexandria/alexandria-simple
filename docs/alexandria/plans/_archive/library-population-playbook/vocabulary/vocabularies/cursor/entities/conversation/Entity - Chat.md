# Chat

## WHAT: Definition

_Stub — a conversation thread between the Developer and the AI. Chat is distinct from the autonomy-ladder surfaces (Tab, Inline Edit, Composer, Agent): it is an open-ended conversational interface orthogonal to the tier escalation. A Chat thread persists as a named Session that the Developer can return to. The Chat surface is where the Developer asks questions, explores code, or discusses architecture without necessarily asking for a direct file edit._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Session]] (Chat threads persist as Sessions), [[Surface - Chat]] (the surface this entity is authored and read within), [[Entity - Workspace]] (Chat context is scoped to the current Workspace)._
