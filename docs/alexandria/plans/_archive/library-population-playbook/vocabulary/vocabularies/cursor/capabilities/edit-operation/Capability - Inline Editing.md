# Inline Editing

## WHAT: Definition

_Stub — the capability of issuing a natural-language instruction scoped to a selected region of code and receiving a proposed rewrite of that region. The Developer selects text, invokes Inline Editing, types an instruction, and Cursor proposes a diff bounded to the selection. Inline Editing is what the Inline Edit surface provides._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Inline Edit]] (the surface on which Inline Editing is experienced), [[Pattern - Autonomy Ladder]] (Inline Editing is the second-tier capability), [[Pattern - Apply-and-Review]] (the Developer reviews and accepts or rejects the Inline Editing proposal), [[Capability - Applying]] (Applying commits the accepted inline diff to the file)._
