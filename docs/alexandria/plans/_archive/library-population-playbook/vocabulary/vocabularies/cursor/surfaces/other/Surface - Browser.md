# Browser

## WHAT: Definition

_Stub — the embedded browser surface that the Agent can open to read web content during an autonomous loop. The Browser allows the Agent to retrieve documentation, look up error messages, or read reference pages without leaving the Cursor environment. The Developer can observe the Agent's browser navigation as part of the loop's progress trace._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Agent Surface]] (the Agent Surface is the context in which the Browser is opened), [[Role - Agent]] (the Agent is the primary actor that uses the Browser during a loop), [[Pattern - Background Loop]] (Background Agents may also use the Browser in their cloud-provisioned workspace)._
