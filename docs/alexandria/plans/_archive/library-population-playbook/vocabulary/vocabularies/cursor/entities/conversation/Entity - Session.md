# Session

## WHAT: Definition

_Stub — a durable Chat thread with full history. A Session persists across Cursor restarts and is addressable by the Developer in the Chat history panel. Sessions allow the Developer to return to a prior conversation, resume context, and continue an interrupted train of inquiry or task._

_Stub — links to: [[Entity - Chat]] (the Chat entity that a Session stores and persists), [[Surface - Chat]] (the surface where Sessions are opened and listed), [[Entity - Checkpoint]] (Checkpoints captured during Agent work are associated with the Session in which the Agent ran)._
