# .cursorrules

## WHAT: Definition

_Stub — the project-level configuration file in which the Developer authors Rules for the Workspace. The `.cursorrules` file lives at the repository root and is committed to version control, making Rules shareable across a team. Named for the system that consumes it — an explicit, artifact-named convention consistent with developer-tool norms (`.eslintrc`, `.prettierrc`, `.gitignore`). The modern Cursor Rules UI provides an equivalent interface; `.cursorrules` is the file-based artifact for teams using version-controlled configuration._
