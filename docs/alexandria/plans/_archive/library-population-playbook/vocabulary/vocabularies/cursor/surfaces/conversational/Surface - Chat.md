# Chat

## WHAT: Definition

_Stub — the conversational surface orthogonal to the autonomy ladder. Chat is the panel where the Developer asks open-ended questions, explores code, discusses architecture, and holds multi-turn conversations with the AI. Chat does not execute file changes directly; it informs, explains, and suggests. It is distinct from the four autonomy-ladder surfaces (Tab, Inline Edit, Composer, Agent) in that it does not propose a diff or take autonomous action — it produces text responses the Developer reads and acts on manually._
