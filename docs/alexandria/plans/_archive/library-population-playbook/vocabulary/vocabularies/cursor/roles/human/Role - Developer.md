# Developer

## WHAT: Definition

_Stub — the primary human role in the Cursor product. The Developer is the operator who opens a Workspace, issues instructions to Tab/Inline Edit/Composer/Agent surfaces, reviews proposed diffs, applies or rejects changes, and manages Rules. The Developer is both the author of code and the director of autonomous agent work._

_Naming-history note: Cursor does not use "User" generically in its interface or documentation. All copy speaks directly to developers — "your codebase," "your rules," "you can apply" — treating the audience as a technical peer rather than an abstract user role. This is a deliberate signature choice: second-person address over third-person role labeling. "Developer" is the canonical third-person noun when a role name is required (e.g., in library cards, API design, documentation). The choice signals audience fit: this product is for developers, and its vocabulary assumes that identity._
