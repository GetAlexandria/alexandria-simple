# Plan

## WHAT: Definition

_Stub — the subscription tier that determines the Developer's monthly Fast Request quota, model access, team features, and Background Agent availability. Cursor offers Pro, Business, and Enterprise tiers. Plan is the economy noun that bundles quota (Fast Requests), access (model roster), and feature gating (Business/Enterprise collaboration features) into a named package._
