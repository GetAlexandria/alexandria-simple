# Composing

## WHAT: Definition

_Stub — the capability of issuing a natural-language instruction that spans multiple files and receiving a complete diff covering all affected files. The Developer types an instruction in the Composer surface and Cursor proposes a coordinated multi-file change. Composing is what the Composer surface provides — it expands scope beyond a single selection to the full codebase._
