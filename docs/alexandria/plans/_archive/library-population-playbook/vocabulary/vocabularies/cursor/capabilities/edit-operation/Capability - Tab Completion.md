# Tab Completion

## WHAT: Definition

_Stub — the capability of accepting an AI-generated code suggestion at the current cursor position with a single keypress. Tab Completion is what the Tab surface provides: the Developer types, the AI predicts what comes next, and the Tab key accepts the prediction. The capability is always-on and requires no explicit invocation beyond typing._

## WHERE: Ecosystem

_Stub — links to: [[Surface - Tab]] (the surface on which Tab Completion is experienced), [[System - Tab Engine]] (the inference pipeline that generates the completions), [[Pattern - Autonomy Ladder]] (Tab Completion is the entry point to the autonomy ladder)._
