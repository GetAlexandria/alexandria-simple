# Tab

## WHAT: Definition

_Stub — the autocomplete-suggestion surface; the first and lowest-autonomy tier on Cursor's autonomy ladder. Tab renders an inline ghost-text suggestion as the Developer types; accepting it requires a single keystroke — the Tab key. The Developer retains full control: every character either comes from their own keystrokes or from a single Tab press. Tab does not initiate multi-line rewrites, cross-file changes, or autonomous loops._

_Tab is Cursor's signature Pattern in miniature: the surface is named for the gesture that fires the acceptance, not for the model running behind it, not for the inference that produced the suggestion. This is the MDA-inversion test at its sharpest. Tab is also the entry point to the autonomy ladder that `families.md` identifies as Cursor's defining contribution to agentic-software vocabulary. The four-tier escalation — Tab → Inline Edit → Composer → Agent — names each tier from the developer's felt encounter during the moment. Tab: the keystroke. Inline Edit: the selected text region. Composer: the multi-file drafting panel. Agent: the autonomous loop. Every tier is aesthetics-named, none are mechanism-named. This is the cleanest surface naming in the agentic-software space as of the families.md survey, and the reason Cursor is cited as the positive exemplar of MDA-inversion-avoided in Family 2._
