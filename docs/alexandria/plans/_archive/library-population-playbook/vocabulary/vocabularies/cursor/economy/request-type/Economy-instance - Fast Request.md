# Fast Request

## WHAT: Definition

_Stub — a premium-model invocation that counts against the Developer's monthly Fast Request quota. Fast Requests use the highest-capability models in Cursor's model roster (e.g., GPT-4o, Claude Sonnet) and provide the fastest, highest-quality responses. Once the monthly quota is exhausted, the Developer either upgrades their Plan or continues with Slow Requests._

## WHERE: Ecosystem

_Stub — links to: [[Economy-instance - Slow Request]] (the unlimited-but-throttled alternative when the Fast Request quota is exhausted), [[Economy-instance - Plan]] (the Plan determines the monthly Fast Request quota), [[Surface - Composer]] (Composer interactions consume Fast Requests), [[Surface - Agent Surface]] (Agent loops consume Fast Requests per tool call)._
