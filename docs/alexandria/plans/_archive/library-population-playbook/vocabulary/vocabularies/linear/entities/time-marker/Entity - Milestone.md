# Milestone

## WHAT: Definition

_Stub — a dated marker within a Project that groups a set of Issues toward an interim checkpoint. A Milestone is distinct from a Cycle: a Cycle is Team-level and recurring (the time-box rhythm); a Milestone is Project-level and one-off (a named checkpoint inside a Project's lifetime). Multiple Milestones can exist within a single Project; Issues are assigned to a Milestone to signal which checkpoint they belong to._
