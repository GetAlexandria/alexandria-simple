# Assigning

## WHAT: Definition

_Stub — setting an Issue's assignee: the load-bearing ownership gesture in Linear's workflow. Assigning binds a [[Role - Member]] to an Issue, signaling who is responsible for it. A single Issue has one assignee at a time (Linear's model as of current docs); reassigning replaces the previous owner. Assigning is the primary mechanism by which work is claimed and distributed across the Team._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Issue]] (the Entity being assigned), [[Role - Member]] (the Role that receives the assignment), [[System - Notification Routing]] (Assigning triggers a notification to the new assignee), [[Surface - Inbox]] (the assignee's Inbox receives the Assigning event)._
