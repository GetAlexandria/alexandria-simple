# Filtering

## WHAT: Definition

_Stub — constraining a View's visible contents by one or more predicates: assignee, Label, Workflow State, Cycle, priority, date, and more. Filters are composable (AND / OR logic); the result is a constrained View that persists as long as the filter is active. Note on naming: the UI menu item reads "Filter" (the noun form), but the canonical capability is "Filtering" per [[Standard - Linear Nomenclature Signature]]'s gerund convention for capability verbs. The altLabel "Filter" captures the form users encounter in the menu._

## WHERE: Ecosystem

_Stub — links to: [[Surface - View]] (the Surface Filtering constrains), [[Entity - Label]] (a primary filter predicate), [[Capability - Search]] (complementary: Search finds across the Workspace; Filtering constrains within a View), [[Entity - Cycle]] (Cycle is a Filtering predicate when scoping to a time-box)._
