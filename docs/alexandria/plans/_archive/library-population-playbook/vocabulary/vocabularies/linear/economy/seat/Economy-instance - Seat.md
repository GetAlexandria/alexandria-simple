# Seat

## WHAT: Definition

_Stub — a licensed user slot. Members consume Seats; Guests do not consume full Seats (or consume partial Seats, depending on Plan). The Seat is the unit of seat-based pricing: the [[Economy-instance - Plan]] sets the Seat count and per-Seat price; the [[Role - Owner]] manages how many Seats are provisioned._

## WHERE: Ecosystem

_Stub — links to: [[Role - Member]] (Members consume Seats), [[Role - Guest]] (Guests do not consume full Seats), [[Economy-instance - Plan]] (the Plan defines Seat limits and per-Seat pricing), [[Role - Owner]] (the Owner manages Seat provisioning and billing)._
