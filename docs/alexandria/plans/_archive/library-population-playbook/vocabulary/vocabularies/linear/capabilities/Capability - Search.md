# Search

## WHAT: Definition

_Stub — full-text and structured search across Issues, Projects, comments, and documents within the Workspace. Search is bound to Linear's keyboard shortcut convention (typically a single keypress to invoke); the shortcut-first design reflects Linear's speed-oriented product philosophy. Note: "Search" is a noun-form capability rather than a gerund — an intentional exception to the gerund convention in [[Standard - Linear Nomenclature Signature]] because "Search" functions as both the capability label and the surface invocation noun._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Issue]] (primary Search target), [[Entity - Project]] (Projects are searchable), [[Capability - Filtering]] (complementary capability; Search finds across the Workspace, Filtering constrains within a View), [[Entity - Workspace]] (Search scope; bounded to the Member's accessible Workspace)._
