# Activity Feed

## WHAT: Definition

_Stub — a time-ordered display of changes across a Workspace, Team, or Project scope. Activity Feed is a genuine facet concept: as a Surface it is the display where Members see what has changed; as a Pattern it is the recurring change-stream shape that appears wherever a temporal event log is needed (on an Issue detail, on a Project, at Workspace level). The same underlying pattern instantiates at multiple scopes._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Issue]] (Issue-level Activity Feed shows comment and state-change history), [[Entity - Project]] (Project-level Activity Feed shows all Issue changes within the Project), [[Entity - Workspace]] (Workspace-level Activity Feed is the broadest scope), [[Surface - Inbox]] (Inbox is the Member-scoped, action-required subset of the Workspace Activity Feed)._
