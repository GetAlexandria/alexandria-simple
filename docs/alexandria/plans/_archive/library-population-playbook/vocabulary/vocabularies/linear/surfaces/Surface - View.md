# View

## WHAT: Definition

_Stub — a named query-and-display surface over Issues. Each View carries: a filter set, a sort, a grouping, and a display mode (Board / List / Calendar). A View is the user's primary way of *encountering* their Issues; the Issue is the data, the View is the lens._

_Display mode is a sub-type — Board View, List View, Calendar View, Gantt View — each with its own rendering conventions. Names follow the display-mode convention from [[Standard - Linear Nomenclature Signature]]._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Issue]] (the data), [[Entity - Team]] / [[Entity - Workspace]] (the Views are scoped to one), [[Capability - Filtering]] / [[Capability - Sorting]] (composed inside a View)._
