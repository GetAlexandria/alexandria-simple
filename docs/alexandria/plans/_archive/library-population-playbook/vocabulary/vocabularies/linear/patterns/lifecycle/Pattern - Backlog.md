# Backlog

## WHAT: Definition

_Stub — the queue/buffer Pattern where Issues without active Cycle commitment accumulate. As a Pattern, Backlog is the "Issues waiting their turn" buffer behavior: Issues flow into the Backlog when created or when they miss a Cycle, and flow out when a Member commits them to an upcoming Cycle or closes them._

_This is another dual-facet case. "Backlog" also names one of Linear's default [[System - Workflow State]] values — the named bucket that implements the buffer. The Pattern is the queue behavior; the State is the specific named implementation of it. Teams can rename the State (call it "Ready" or "Queued") while still running the Backlog Pattern. The Pattern is the behavior; the State is one instantiation of it. This mirrors the [[Pattern - Cycle]] / [[Entity - Cycle]] split: same word, two facets, two cards._

## WHERE: Ecosystem

_Stub — links to: [[System - Workflow State]] (Backlog is one of the default Workflow States implementing this Pattern), [[Pattern - Triage]] (Triage is the routing Pattern that feeds the Backlog), [[Entity - Cycle]] (Cycles pull Issues from the Backlog), [[Entity - Issue]] (the Items that accumulate in the Backlog)._
