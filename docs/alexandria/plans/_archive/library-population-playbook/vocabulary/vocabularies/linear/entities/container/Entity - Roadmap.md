# Roadmap

## WHAT: Definition

_Stub — a curated collection of Projects and Initiatives laid out across time, with status indicators and target dates. Roadmap is a genuine facet concept: it is both an Entity (a saved, addressable artifact with a name and owner) and a Surface (the display mode where the temporal layout is visible). A Roadmap is not generated automatically from all Projects; it is explicitly curated by a Member who chooses which Projects and Initiatives to include and in which temporal arrangement._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Initiative]] (the strategy-level containers that appear on Roadmaps), [[Entity - Project]] (the scope containers Roadmaps display), [[Entity - Milestone]] (dated markers within Projects that appear on the Roadmap timeline), [[Role - Member]] (the curator and viewer of a Roadmap)._
