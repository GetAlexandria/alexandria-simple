# Dashboard

## WHAT: Definition

_Stub — a multi-widget composed Surface showing Project status, Cycle progress, and configurable Issue metrics. The Dashboard is primarily read-only aggregate display; it assembles data from multiple Entities into a single surveillance surface. Per the families.md Surfaces vocabulary, Dashboard is "named for what the user does there (monitor)" — not for the data layer backing it._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Project]] (Project status appears as a Dashboard widget), [[Entity - Cycle]] (Cycle progress metrics surface on the Dashboard), [[Entity - Issue]] (Issue counts and state distributions underlie Dashboard widgets), [[Surface - Activity Feed]] (complementary Surface; Activity Feed is time-ordered events, Dashboard is aggregated status)._
