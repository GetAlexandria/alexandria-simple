# Issue

## WHAT: Definition

_Stub — the unit of work. Linear's chosen Item noun. Each Issue has an identity (TEAM-123), a [[System - Workflow State]], an assignee ([[Role - Member]]), optional [[Entity - Project]] and [[Entity - Cycle]] bindings, and a description body._

_Notable: "Issue" is itself a near-MDA-inversion case (it sounds like the engineering term inherited from bug-tracking). Linear adopts it because the dominant audience is engineering teams, where Issue is the felt-experience term. Non-engineering Linear customers experience some import friction — name flagged in [[Standard - Linear Nomenclature Signature]] as one of the few survivors of the process-vocabulary lineage._
