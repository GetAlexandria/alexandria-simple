# Admin

## WHAT: Definition

_Stub — workspace-level configuration rights without billing ownership. An Admin can manage Members, integrations, and Workspace settings, but cannot delete the Workspace or change the Plan — those actions are reserved for the Owner Role. The Admin/Owner split is the standard internal-operator cut: one person holds the commercial relationship; others hold operational rights._

## WHERE: Ecosystem

_Stub — links to: [[Role - Owner]] (the billing-holder above Admin), [[Role - Member]] (the users Admin manages), [[Entity - Workspace]] (the scope of Admin rights), [[System - Permission Model]] (the rules Admin can configure but not fully override)._
