# Triage

## WHAT: Definition

_Stub — the recurring routing pattern where incoming Issues (from integrations, customer reports, internal slack imports) land in a per-Team Triage queue and get assigned: Project, Cycle, Workflow State, assignee, priority. Triage is both a Pattern (the recurring routing action) AND a Workflow State (the queue's name)._

_The dual role is intentional. The State "Triage" gives incoming Issues a literal home; the Pattern "Triaging" gives the Team a regular workflow rhythm — typically a 5–15 minute daily session. This is Linear's named instance of the universal "incoming-work routing" Pattern that every productivity SaaS has but most don't name._
