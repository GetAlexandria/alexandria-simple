# Initiative

## WHAT: Definition

_Stub — a strategy-level container above Projects. An Initiative groups multiple Projects toward a higher-order outcome, providing a named anchor for work that spans Teams and Cycles. Linear's three-axis cut — Project (scope), Cycle (time), Initiative (strategy) — is what distinguishes it from competitors that collapse all three into a single "Sprint" or "Roadmap" concept. An Initiative does not repeat like a Cycle and does not carry a single Team's Issues directly; it aggregates Projects._
