# Team

## WHAT: Definition

_Stub — a sub-container inside a Workspace that owns its own Issues, Cycles, Workflow States, Labels, and Triage queue. Linear's distinctive second-level container — most products in this family have Workspace → Project, Linear inserts Team between, which lets one Workspace host multiple teams with disjoint working vocabularies._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Workspace]] (parent containment), [[Role - Member]] (Members belong to Teams), [[Entity - Project]] (Projects are scoped to a Team or span Teams), [[Entity - Cycle]] (Cycles are Team-scoped), [[System - Workflow State]] (each Team has its own Workflow State set)._
