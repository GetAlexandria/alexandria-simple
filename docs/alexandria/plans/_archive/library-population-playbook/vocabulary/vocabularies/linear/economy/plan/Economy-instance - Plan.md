# Plan

## WHAT: Definition

_Stub — a bundle of Seats, features, and limits at a price point. Linear's Plans (Free, Standard, Plus, Enterprise) are the Workspace's billing relationship with the product. The [[Role - Owner]] is responsible for the Plan; changing the Plan, upgrading, or cancelling are Owner-only actions. Plan gates which features are available (e.g., Customer Requests, advanced Workflow States, priority support) and sets the Seat count ceiling._

## WHERE: Ecosystem

_Stub — links to: [[Role - Owner]] (the Role responsible for the Plan), [[Economy-instance - Seat]] (the Seat limit is set by the Plan), [[Entity - Workspace]] (each Workspace has one Plan), [[Role - Guest]] (Guest Seat consumption rules vary by Plan)._
