# Project

## WHAT: Definition

_Stub — a scope-bounded unit of work that holds multiple Issues toward a named outcome. Distinct from [[Entity - Cycle]] (scope is what; Cycle is when). Distinct from Initiative (Project is delivery; Initiative is strategy). Linear's load-bearing cut: scope, time, and strategy are three separate axes — not one "sprint" noun._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Team]] (Projects are Team-owned or cross-Team), [[Entity - Issue]] (Issues belong to a Project), [[Pattern - Triage]] (incoming Issues route through Triage to a Project or stay project-less)._
