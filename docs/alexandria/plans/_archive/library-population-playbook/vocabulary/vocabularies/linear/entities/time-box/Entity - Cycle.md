# Cycle

## WHAT: Definition

_Stub — a recurring time-box (typically 1–4 weeks) that bounds a slice of Team work. Issues belong to at most one Cycle at a time. Distinct from [[Entity - Project]] (scope) and Initiative (strategy)._

_The naming is deliberate. "Sprint" is the process-vocabulary equivalent inherited from Agile/Scrum; Linear renames it to Cycle to neutralize the process-fit when Linear is sold to teams that don't run Agile (design, ops, hardware). This is the canonical example in [[Standard - Linear Nomenclature Signature]] of process-vocabulary leak avoidance._

## WHERE: Ecosystem

_Stub — links to: [[Entity - Team]] (Cycles are Team-scoped), [[Entity - Issue]] (the Cycle is a property on Issues), [[Pattern - Triage]] (incoming Issues land cycle-less and get cycle-assigned during Triage)._
