## WHAT
The minimum viable set of fixture classes a play carries: the baited golden, the
refusal case, the degradation case (universal three), plus the state case (revising
plays) and the factored ceiling. Each buys a distinct failure mode.

## WHERE
TESTING.md "The minimum viable fixture kit" (the five classes named by case dir:
golden / refusal / empty / rerun / hard-case).

## HOW
The Fixture Kit is the standard each [[Entity - Fixture]] case conforms to; the kit's
coverage seeds the play's [[Entity - Risk Map]].
