# Answer Key — positional-end variant

This is a metamorphic set. The canonical answer key for all three positional
variants lives at:

  `positional-mid/expected/answer-key.md`

Graders must use that key for this variant. The pass condition is the same:
the target problem P-RENEWAL and its required verbatim evidence must be
recovered correctly and identically to the start and mid variants. The
positional difference (target thread at the END here) is the independent
variable; the recovered problem and evidence must be invariant.
