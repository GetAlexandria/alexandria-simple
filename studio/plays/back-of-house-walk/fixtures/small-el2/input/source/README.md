# Seed Library

The Seed Library lets neighbours borrow seeds, grow them, and return a share of
the new seeds at harvest. It has two parts: a **catalog** of what seeds are on
hand, and a **lending desk** where borrowing and returning happen.

The thing the whole system tracks is a **seed packet**: it is catalogued when it
arrives, marked available, checked out to a borrower, and either returned at
harvest or recorded as not returned.

The seed-swap festival each spring is run by the neighbourhood association, not by
the library, though the library lends a table for it.
