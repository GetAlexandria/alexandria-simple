# The Catalog

The catalog holds every seed packet the library has on hand. A **librarian**
adds a packet when a donation arrives: the packet is given a shelf code, its
variety recorded, and it is marked available.

Each variety carries a **germination standard** — the share of seeds expected to
sprout — copied from the grower's note. The catalog is meant to track the actual
germination rate a variety achieves once borrowers report back, but no report has
ever been recorded, so that number is always blank.

When a packet's last seeds are checked out, it is marked empty and drops off the
available shelf.
